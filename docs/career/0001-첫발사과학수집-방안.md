# 첫 발사 + 커빈 과학 수집 계약 동시 수행 방안

작성 기준: 2026-11-08, 세이브 `career`, UT 134  
검증: 2026-11-08, 세이브 `dev`(career 사본). 아래 낙하산 절차로 계약 두 건 완료 확인.

## 1. 목표·비범위

계약 두 건을 비행 한 번으로 완료한다.

| 계약 | ID | 선금 | 완료 보상 | 과학 | 평판 |
|---|---|---|---|---|---|
| 첫번째 기체를 발사하세요! | 14356311891 | 1,120 | 2,080 | 1 | 1 |
| 커빈에서 과학자료 수집하기. | 16751052846 | 2,240 | 4,160 | 1 | 2 |
| 합계 | | 3,360 | 6,240 | 2 | 3 |

비범위: 「대기권을 탈출해 보세요!」, 「커빈 궤도 형성하기!」. 이번 기체로는 고도가 부족하다. 시설 업그레이드와 기술 연구도 이번 범위에 넣지 않는다.

## 2. 현재 상태와 완료 조건

현재 상태:

- 자금 25,000, 과학 0, 평판 0. 모든 시설이 레벨 0이다.
- 해금 파트: Mk1 사령선, KV-1 귀환선, RT-5 플리, Mk16 낙하산, 기본 날개, 신비한 구™ 보관함, 모듈식 대들보, EVA 제트팩·개인용 낙하산
- 승무원: 제베디아·발렌티나(Pilot), 빌(Engineer), 밥(Scientist). 모두 레벨 0이고 Available이다.
- 비행 기록이 없다. 이번이 이 세이브의 첫 비행이다.

완료 조건:

- 첫 발사: 기체가 발사대를 떠나면 완료된다.
- 과학 수집: 커빈에서 얻은 과학 자료를 회수하거나 전송하면 완료된다.
- 두 계약 모두 발사 전에 수락해 Active 상태여야 한다.

## 3. 기체

스톡 기체 `Jumping Flea`(VAB)를 고치지 않고 그대로 쓴다. 해금된 파트만으로 구성되어 있다.

| 파트 | 수량 | 단가 | 역할 |
|---|---|---|---|
| Mk1 사령선 (`mk1pod.v2`) | 1 | 600 | 승무원 1, 승무원 보고 |
| Mk16 낙하산 (`parachuteSingle`) | 1 | 422 | 사령선 위, 스테이지 0 |
| RT-5 플리 (`solidBooster.sm.v2`) | 1 | 200 | 사령선 아래, 스테이지 1 |
| 기본 날개 (`basicFin`) | 3 | 25 | 플리에 대칭 3 |
| 신비한 구™ (`GooExperiment`) | 2 | 800 | 사령선 옆에 대칭 2 |

- 총비용은 약 2,897이다.
- 스테이지 순서: 1번이 RT-5 점화, 0번이 낙하산 전개다.
- 디커플러가 해금되지 않아 다 탄 플리를 붙인 채로 내려온다.
- `read_craft` 결과에 구 위치 경고(0.18 m, 180°)가 나온다. 저장된 파일을 그대로 발사하므로 이번 비행에는 영향이 없다.

## 4. 승무원

제베디아 커맨(Pilot)이 탑승한다. 레벨 0 파일럿도 SAS 안정 유지를 쓸 수 있다. 제베디아가 탈 수 없으면 발렌티나가 대신 탄다.

## 5. 절차 (kspbridge 도구 순서)

1. 계약 수락
   - `accept_contract` `14356311891`, `accept_contract` `16751052846`
   - `list_contracts`로 두 건이 Active인지 확인
2. 발사대 준비와 점검 (rule `ksp/launch-preflight.md`)
   - `launch_craft` `Jumping Flea`, 승무원 제베디아
   - `setup_launch_ui`: 응답의 `maneuver_mode`·`deltav_info`·`resources`가 모두 `ok: true`인지 확인
   - `get_stages`: 스테이지 1의 TWR이 1.5 이상인지 확인. 궤도 비행이 아니므로 Δv는 도달 고도를 짐작하는 참고값으로만 본다.
   - 점화 전에 화면 셋팅 결과, Δv, TWR을 보고
3. 발사대에서 과학 실험 (LaunchPad)
   - `get_science`로 할 수 있는 실험 확인
   - 승무원 보고(crewReport)와 구 #1을 `run_experiment`
   - 결과 창이 뜨면 `close_experiment_dialog`로 닫는다. 창만 닫히고 데이터는 파트에 남는다.
4. 점화
   - `set_sas` on (`enabled: true`)
   - `activate_next_stage`로 RT-5 점화
   - 발사대를 떠나면 `list_contracts`로 첫 발사 계약이 완료됐는지 확인
5. 정점 근처에서 낙하산 스테이지 (스킬 `ksp-reentry-recovery`의 3 km/250 m/s 패턴은 이 기체에 쓰지 않는다)
   - Jumping Flea는 준궤도 호프라 하강 중 3 km 구간에서도 표면 속도가 대략 250–290 m/s로 유지된다. `altitude_asl <= 3000 ∧ speed_surface <= 250`은 발화 시점이 너무 늦거나, 폴백(`altitude_terrain <= 1000`)이 과속에서 전개되어 Mk16이 찢어진다.
   - 발사대에서는 `altitude_asl <= 3000 ∧ speed_surface <= 250`가 이미 참이다. 점화 전에 이 트리거를 장전하면 즉시 RT-5·낙하산이 연속 스테이지된다.
   - 점화 후, 조건이 아직 거짓일 때(상승·연소 중) 장전한다.
   - `chute_ap`: `{all:[altitude_asl >= 8000, speed_surface <= 100]}` → `{type:'stage'}`
   - `list_triggers`로 armed인지 확인한 뒤, 정점에 가까워져 발화하면 `fired_value`를 기록한다. 검증 비행에서는 약 11.7 km·100 m/s에서 발화했다.
   - Mk16은 스테이지 후 자체 고도/압력 설정으로 전개한다. 정점 저속에서 스테이지하면 하강 중 안전 고도에서 열린다.
6. 비행 중 과학 실험 (FlyingLow)
   - 연소가 끝나고 정점에 가까울 때(낙하산 스테이지 전후) `get_science`로 구 #2의 `can_run_now`를 확인한 뒤 `run_experiment`
   - 결과 창이 뜨면 `close_experiment_dialog`로 닫는다.
7. 하강
   - 시간 가속은 쓰지 않는다. 하강이 짧아 가속할 이유가 없다.
   - `wait_until` `{any:[situation == LANDED, situation == SPLASHED]}`, `timeout=120`, `abortOn=['part_lost']`를 착지할 때까지 반복
   - `part_lost`로 중단되면 `get_flight_log`로 무엇이 부서졌는지 읽은 뒤, 장면을 바꾸기 전에 `revert_to_launch`를 제안한다.
8. 회수와 결과 확인
   - 회수 전에 `get_science`로 저장된 데이터(승무원 보고, 구 2개)를 확인
   - `recover_vessel`
   - `list_contracts`: 두 건 Completed(Active 목록에서 사라짐)
   - `list_crew`: 제베디아 Available
   - `get_career`: 자금·과학·평판 증가 확인
   - 최대 G, 착지 속도, 트리거가 발화한 값을 보고

## 6. 위험과 대응

| 위험 | 대응 |
|---|---|
| 점화 전에 3 km/250 m/s 트리거를 장전 | 패드에서 조건이 이미 참이라 즉시 스테이지된다. 점화 후에만 장전하고, 이 기체에는 정점 저속 조건을 쓴다. |
| 하강 중 3 km/250 m/s·1 km 폴백을 씀 | Jumping Flea는 3 km에서도 250 m/s 초과가 유지된다. 폴백이 과속에서 전개되면 Mk16이 찢어진다. `chute_ap`만 쓴다. |
| 플리를 붙인 채 내려오다 기체가 뒤집힘 | Mk16은 기체 방향과 관계없이 전개된다. SAS는 켜 둔다. |
| 실험 데이터가 저장되지 않음 | 실험할 때마다 `get_science`로 저장된 데이터를 확인. `discard_science`는 쓰지 않는다. |
| 승무원이 사망하는 등 되돌릴 수 없는 사고 | 장면을 바꾸기 전에 바로 `revert_to_launch`를 제안 |
| 트리거가 지워짐 | 활성 기체나 장면이 바뀌면 트리거가 지워진다. 발사 뒤 기체를 바꾸지 않는다. |
