# 동력착륙 개발

방안 0028, 설계 0029. 새 파일은 `src/KspBridge.Logic/Flight/Modes/LandMode.cs`다. 바뀌는 코드는 `src/KspBridge.Logic/Flight/Plan.cs`(Mode 분기), `src/KspBridge.Logic/Flight/FlightEvents.cs`(읽기 전용 `InTrial` 추가)와 `src/KspBridge.App.Tools/FlightTools.cs`(도구 설명), 문서는 ReadMe와 0005다. 로더·Coordinator·AutoStager는 바꾸지 않는다.

## 공통 규칙

- 배포는 `dotnet build` 뒤 `reload_mod`(Logic). 씬 전환·reload·발사 전에 `get_status`로 다른 비행이 진행 중인지 확인한다.
- 검증은 MCP 응답(`get_flight`, `get_flight_events`, `get_status`)과 KSP.log `[KspBridge] land` 줄로만 한다. 화면 확인·키 입력을 요청하지 않는다.
- 매 틱 경로는 할당·LINQ 없이 쓴다. `bottom_offset` 측정(부품·collider 순회)만 아래 단위 2의 갱신 조건에서 돈다.
- 실측 기체 L(단위 3부터): Mk1 Command Pod + FL-T400 + LV-T45 "Swivel" + LT-1 착륙 다리 3개(대칭)를 editor 도구로 만든다. 1단, Kerbin TWR > 1. 저장 이름 `KspBridge-Land-L`.
- 실측 계획 골격: `attitude`(pitch 85, heading 270, throttle 1, `on_start: ["stage"]`, until `apoapsis >= 3000`) → `coast`(reference none, warp false, until `vertical_speed < -5`) → `land`. 서쪽(heading 270)으로 기울여 KSC 발사대·시설과 동쪽 해안을 벗어난 지형에 내린다(설계 0029 "실측", 검토 R1-1-B-9). 기본값으로 접지하지 못하면 실측값으로 인자를 고치고 설계 0029를 갱신한다.
- 파손 확인 이벤트는 `PartLossLog`가 내는 `part_lost`·`part_collision`·`part_limit`·`part_joint_break`다(검토 R1-1-B-4).

## 단위 2: 지면 고도 보정과 착륙 다리

- **대상**: `LandMode.MeasureBottom`, `LandMode.Lowest`, `LandMode.Height`, `Update`의 Gear 처리, `FlightEvents.InTrial`
- **코드 초안**:

```csharp
/// <summary>Distance from the CoM to the lowest collider point along the vessel's −up axis (ReferenceTransform).</summary>
private static double MeasureBottom(Vessel v)
{
    Vector3 com = v.CoMD, down = -v.ReferenceTransform.up;
    Vector3 far = com + down * 1000f;
    double max = 0;
    List<Part> parts = v.parts;
    for (int i = 0; i < parts.Count; i++)
    {
        Collider[] cs = parts[i].GetPartColliders();
        for (int j = 0; j < cs.Length; j++)
        {
            Collider c = cs[j];
            if (c == null || !c.enabled || c.isTrigger) continue;
            max = Math.Max(max, Lowest(c, com, down, far));
        }
    }
    return max;
}

/// <summary>ClosestPoint only for the shapes Unity supports (it returns the query point unchanged for others);
/// otherwise the lowest of the 8 world AABB corners (below the real shape: conservative).</summary>
private static double Lowest(Collider c, Vector3 com, Vector3 down, Vector3 far)
{
    MeshCollider mc = c as MeshCollider;
    if (c is BoxCollider || c is SphereCollider || c is CapsuleCollider || (mc != null && mc.convex))
    {
        return Vector3.Dot(c.ClosestPoint(far) - com, down);
    }
    Bounds b = c.bounds;
    double max = double.NegativeInfinity;
    for (int k = 0; k < 8; k++)
    {
        Vector3 p = new Vector3((k & 1) == 0 ? b.min.x : b.max.x, (k & 2) == 0 ? b.min.y : b.max.y, (k & 4) == 0 ? b.min.z : b.max.z);
        max = Math.Max(max, Vector3.Dot(p - com, down));
    }
    return max;
}

private double Height(Vessel v)
{
    double ut = Planetarium.GetUniversalTime();
    bool gear = v.ActionGroups[KSPActionGroup.Gear];
    bool remeasure = v.parts.Count != _partCount || gear != _gearState
        || (ut < _gearSettleUntil && ut - _measuredUt >= 0.5);   // legs animate after the group turns on
    if (remeasure)
    {
        _bottom = MeasureBottom(v);
        _partCount = v.parts.Count; _gearState = gear; _measuredUt = ut;
    }
    return v.radarAltitude - _bottom;
}
```

## 단위 3: 감속 제어와 자세

- **대상**: `LandMode.Update`(연소 시작·스로틀·마지막 구간·자세), `Begin`
- **코드 초안**:

`Update` 순서는 설계 0029 "동작"을 따른다: 접지 후 처리(단위 5) → `h`·속도 계산 → Gear(단위 2) → 자세 목표 → 추력 없음 반환 → 연소 시작·스로틀 → 착륙 불가(단위 4). Gear 처리는 추력 없음 반환보다 **앞**에 둔다. 그래야 엔진 미점화 trial(`409 no_thrust`)에서도 Gear 블록이 실행되어 `InTrial` 조건을 단위 2 검증으로 확인할 수 있다(검토 R2-1-B-3).

```csharp
Vector3d up = (v.CoMD - v.mainBody.position).normalized;
double r = (v.CoMD - v.mainBody.position).magnitude;
double g = v.mainBody.gravParameter / (r * r);
double vv = -v.verticalSpeed;                                     // down positive
double vh = Vector3d.Exclude(up, v.srf_velocity).magnitude;
double cos = Vector3d.Dot(v.ReferenceTransform.up, up);
double aMaxV = EngineModel.MaxAccel(v) * cos;

// attitude: up, tilted toward surface retrograde by at most max_tilt(vh)
double maxTilt = Clamp(vh * TiltPerMs, 0, 90);
AttitudeTarget att = AttitudeTarget.RotateTowards(up, -v.srf_velocity, maxTilt);

// ... Gear (단위 2) here, before the no-thrust return

if (EngineModel.MaxAccel(v) <= 0) return new ModeCommand(att, 1);   // no engine thrust (not tilt): Coordinator waits or no_thrust

double aReq = vv > 0 && h > _finalAlt
    ? (vv * vv - _finalSpeed * _finalSpeed) / (2 * (h - _finalAlt)) + g
    : double.NaN;
if (!_burning)
{
    double maxAccel = EngineModel.MaxAccel(v);
    Judge(v, t, h, vv, aReq, maxAccel, "best", g);   // before the burn too, against the best attitude (단위 4)
    // normal start: axis near the actual target direction (not the tilt limit), judged with the target's cos so an axis
    // tilted past the target does not start high; forced starts: near the ground, or no margin even with a vertical axis
    Vector3d dir = att.Direction(v);
    double alignErr = Vector3d.Angle(v.ReferenceTransform.up, dir);
    double aMaxVTarget = maxAccel * Vector3d.Dot(dir, up);
    string why = vv <= MinStartVv ? null
        : h <= _finalAlt ? "final_altitude"
        : aReq >= _margin * maxAccel ? "no_margin"
        : alignErr <= AlignDeg && aReq >= _margin * aMaxVTarget ? "aligned"
        : null;
    if (why == null) return new ModeCommand(att, 0);
    _burning = true;
    _aligning = why != "aligned" && alignErr > AlignDeg;   // forced start with the axis still turning: until first alignment
    Log("burn start: why=" + why + " h=" + F(h, 1) + " vv=" + F(vv, 2) + " vh=" + F(vh, 2) + " align_err=" + F(alignErr, 1) +
        " cos=" + F(cos, 3) + " a_req=" + F(aReq, 2) + " a_max=" + F(maxAccel, 2) + " a_max_v_target=" + F(aMaxVTarget, 2));
}
double throttle = h > _finalAlt
    ? aReq / aMaxV
    : (g + FinalGain * (vv - _finalSpeed)) / aMaxV;
throttle = cos <= 0 || double.IsNaN(throttle) ? 0 : Clamp01(throttle);
// only after a forced start, until the axis first comes within AlignDeg of the target (latched, never re-armed):
// scale down thrust pointed the wrong way. A normal burn whose moving target the axis lags behind is untouched (결정 8).
double burnAlignErr = Vector3d.Angle(v.ReferenceTransform.up, att.Direction(v));
if (_aligning && burnAlignErr <= AlignDeg)
{
    _aligning = false;
    Log("aligned after forced start: align_err=" + F(burnAlignErr, 1) + " h=" + F(h, 1));
}
bool misaligned = _aligning;
if (misaligned) throttle *= Math.Max(0, Math.Cos(burnAlignErr * Math.PI / 180));
```

  - `TiltPerMs` = 5, `FinalGain` = 1, `AlignDeg` = 15, `MinStartVv` = 0.5 상수로 둔다(결정 1·10, 동작 7, 실측 조정).
  - `att.Direction(v)`는 기존 `AttitudeTarget.Direction`(Vector 종류는 저장한 world 방향을 그대로 돌려줌)이다.
  - `vv ≤ 0`(상승 중)이고 `h > h_f`면 `aReq`가 NaN이라 연소 중이면 스로틀 0, 연소 전이면 시작하지 않는다.
  - 자세 조건(`alignErr`)은 시작 판정에서는 정상 시작에만 쓴다. 강제 시작 두 가지는 자세와 관계없이 시작한다(결정 1, 검토 R3-1-B-1·B-2).
  - `_aligning`은 강제 시작(`why`가 `final_altitude`·`no_margin`)으로 연소를 시작했고 그때 축이 목표에서 `AlignDeg`보다 벌어져 있을 때만 켜진다. 축이 처음 15° 안에 들어오면 꺼지고 다시 켜지지 않는다. 켜져 있는 동안만 스로틀에 `max(0, cos(align_err))`를 곱하고(검토 R4-1-B-2), 착륙 불가 판정을 최선 자세 기준으로 하며, 강제 스로틀 1을 하지 않는다(단위 4). 정상 연소 중 목표가 움직여 축이 뒤처지는 경우는 결정 8 그대로 스로틀을 줄이지 않는다(검토 R5-1-B-1).
  - `F`는 `CircularizeMode.F`와 같은 InvariantCulture 서식 도우미다. `burn start` 줄의 필드(`why`, `h`, `vv`, `vh`, `align_err`, `cos`, `a_req`, `a_max`, `a_max_v_target`)를 단위 3·4 검증이 읽는다(검토 R3-1-B-3).
- **검증**: 기체 L로 실측 계획 골격(`land` 기본값) 제출. KSP.log `land burn start`가 지면 고도 수백 m에서 나오고 그 줄이 `why=aligned`(이때 `align_err` 15° 이하) 또는 `why=no_margin`이다. 연소 중 `vertical_speed`가 줄어 `h_f` 근처에서 약 −2 m/s가 된다(`get_flight` 폴링). `coast`를 `reference: "prograde"`로 바꿔(낙하 중 기체 앞이 아래를 향함) 다시 실측하면, `land` 시작 직후가 아니라 자세가 돌아온 뒤(`why=aligned`) 또는 여유가 없어진 시점(`why=no_margin`)에 `burn start`가 나오고, 어느 쪽이든 접지 전에 연소가 시작된다(`touchdown` 전에 `burn start`). 접지 뒤 계획은 단위 5 전까지 끝나지 않으므로 `abort_flight`.
- **선행 단위**: 단위 2

## 단위 4: 착륙 불가 판정

- **대상**: `LandMode.Judge`, `Update`의 연소 중 호출, `Report(string reason, ...)`
- **코드 초안**:

```csharp
/// <summary>Infeasibility on this tick (no latch). aCap: MaxAccel (best attitude) before the burn and while _aligning
/// after a forced start, otherwise the actual vertical capacity aMaxV. Reports once per step and reason; the event's
/// basis field says which capacity a_max is.</summary>
private bool Judge(Vessel v, Telemetry t, double h, double vv, double aReq, double aCap, string basis, double g)
{
    if (!(vv > _finalSpeed)) return false;
    bool infeasible = false;
    if (h > _finalAlt && aReq > aCap)
    {
        infeasible = true;
        Report(v, "accel", aReq, aCap, basis, double.NaN, double.NaN, h);
    }
    double dvLeft = t.Num["total_dv"];
    if (!double.IsNaN(dvLeft) && aCap > g)
    {
        double dvNeed = v.srfSpeed + g * vv / (aCap - g);   // speed + gravity loss over the vertical stop
        if (dvLeft < dvNeed)
        {
            infeasible = true;
            Report(v, "dv", aReq, aCap, basis, dvNeed, dvLeft, h);
        }
    }
    return infeasible;
}

// Update, while burning (after the throttle of 단위 3)
// misaligned (= _aligning: after a forced start, before the first alignment): judge against the best attitude and
// do not force full throttle, so a still-turning axis neither reports a false accel nor burns hard the wrong way
double aCap = misaligned ? EngineModel.MaxAccel(v) : aMaxV;
if (Judge(v, t, h, vv, aReq, aCap, misaligned ? "best" : "actual", g) && !misaligned && cos > 0) throttle = 1;   // this tick only

private void Report(Vessel v, string reason, double aReq, double aMax, string basis, double need, double left, double h)
{
    if (_infeasible.Contains(reason)) return;   // once per step and reason
    _infeasible.Add(reason);
    FlightEvents.Add("landing_infeasible", Coordinator.StepIndex, new Dictionary<string, object>
    {
        ["reason"] = reason, ["a_req"] = R(aReq), ["a_max"] = R(aMax), ["a_max_basis"] = basis,
        ["dv_need"] = R(need), ["dv_left"] = R(left), ["altitude"] = R(h),
    });
}
```

  - 강제 스로틀 1은 그 틱에 판정 조건이 참이고 `vv > v_f`인 동안만이다(설계 0029 결정 5, 검토 R1-1-B-3). 판정이 틀렸을 때(Δv 추정 오차) 하강이 멈춘 뒤 다시 상승하지 않게 하고, 일시 판정 하나로 최대 추력이 고정되지 않게 한다. `_infeasible`은 이벤트 1회 제한에만 쓴다.
  - `R`은 `LandMode`의 private 도우미다. 소수 3자리로 반올림하고 NaN·무한대는 null로 바꾼다. `PartLossLog.R`(`double?`의 null만 처리)은 NaN을 걸러내지 않아 다시 쓰지 않는다.

```csharp
private static object R(double x) => double.IsNaN(x) || double.IsInfinity(x) ? null : (object)Math.Round(x, 3);
```
- **검증**:
  - `dv`: 기체 L(연료 가득)로 실측 계획 골격에서 상승 단계의 until만 `{var: "total_dv", op: "<", value: 150}`으로 바꿔 연료를 거의 다 쓰며 올라간 뒤 `coast` → `land`(검토 R1-1-B-2: 연료를 10%만 넣으면 상승 단계에서 `no_thrust`로 끝나 `land`에 닿지 못함). `landing_infeasible {reason: "dv"}`가 1회 나온다. 연소 중(KSP.log `burn start` 뒤)이고, 강제 시작 뒤 정렬 대기(`_aligning`, KSP.log `aligned after forced start` 전)가 아니며, 기체 축이 수평 위(`cos > 0`)인 틱에서 그 판정이 참이면 `get_flight.propulsion.throttle`이 1이다. 연소 전 틱은 판정이 참이어도 스로틀 0이 정상이다(설계 0029 결정 5, 검토 R6-1-B-1). 정렬 대기 중인 틱은 스로틀 1을 요구하지 않는다(검토 R5-1-B-2). 기체가 부서져도 된다(실측 뒤 `revert_flight`, 실행 전 `get_status` 확인).
  - `accel`: 실측 계획 골격에서 `land`를 `margin: 1`, `final_altitude: 0`으로 제출. 연소 시작 시점이 한계라 엔진 spool-up 지연 동안 `a_req > a_max`가 되어 `reason: "accel"`이 나오는지 확인하고, 판정이 풀린 뒤 스로틀이 계산값(1 미만)으로 돌아오는지 `get_flight` 폴링으로 본다. `accel`이 나오지 않으면 그 사실과 `burn start` 줄의 `a_req`·`a_max`를 기록하고 이 항목은 판정 불가로 보고한다.
- **선행 단위**: 단위 3

## 단위 5: 접지·정지 판정과 reload 인계

- **대상**: `LandMode.Update` 앞부분(접지 뒤), `Save`, `Load`
- **코드 초안**:

```csharp
bool landed = v.situation == Vessel.Situations.LANDED || v.situation == Vessel.Situations.SPLASHED;
double ut = Planetarium.GetUniversalTime();
if (landed && !_touched)
{
    _touched = true; _touchUt = ut;
    FlightEvents.Add("touchdown", Coordinator.StepIndex, new Dictionary<string, object>
    {
        ["vertical_speed"] = R(v.verticalSpeed), ["horizontal_speed"] = R(vh), ["situation"] = v.situation.ToString(),
    });
}
if (_touched)
{
    _stillSince = landed && v.srfSpeed < 0.5 ? (_stillSince ?? ut) : (double?)null;
    if (_stillSince is double s && ut - s >= 2)
    {
        double tilt = Vector3d.Angle(v.ReferenceTransform.up, up);
        FlightEvents.Add("landed", Coordinator.StepIndex, new Dictionary<string, object>
        {
            ["tilt_deg"] = R(tilt), ["tipped"] = tilt > 45, ["time_since_touchdown_s"] = R(ut - _touchUt),
        });
        Done = true;
    }
    return new ModeCommand(AttitudeTarget.Vector(up), 0);
}
```

```csharp
public Dictionary<string, object> Save() => new Dictionary<string, object>
{
    ["burning"] = _burning, ["gear_done"] = _gearDone, ["infeasible"] = new List<object>(_infeasible),

// Load: 위 키 복원(gear_settle_until null = 0), _bottom은 _partCount = -1로 두어 첫 Height에서 다시 잼.
```

- **선행 단위**: 단위 4
