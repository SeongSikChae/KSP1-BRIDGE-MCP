# KspBridge 발사 중계 — 인게임 소리 녹음 개발

방안: [0029-게임소리-방안.md](0029-게임소리-방안.md) · 설계: [0030-게임소리-설계.md](0030-게임소리-설계.md)

작업 단위는 G1~G6이고, G1부터 차례로 진행합니다. G1~G5는 사운드 장치 없이 단위 테스트와 실패 경로로 검증합니다. G6는 사운드 장치를 연결한 뒤 실제로 녹음해서 검증합니다.

---

  - 기존 YAML(게임 소리 키 없음)로 기동하면 기본값이 쓰입니다.
  - `GameVolume: 3`이면 설정 오류(종료 코드 2)가 납니다.
- **선행 단위**: 없음

## G2. 합성 필터 (`FfmpegArgs.Compose`)
- **대상**: `Ffmpeg.cs`의 `Compose(cues, GameTrack? game = null)`, 새 record `GameTrack(string File, double Offset, double Volume)`
- **코드 초안**:
```csharp
public sealed record GameTrack(string File, double Offset, double Volume);

// Compose 안: 안내·비프 입력을 넣은 뒤
if (game is not null)
{
    args.AddRange(["-i", game.File]);
    string align = game.Offset >= 0
        ? $"adelay={Ms(game.Offset)}|{Ms(game.Offset)}"
        : $"atrim=start={(-game.Offset).ToString(CultureInfo.InvariantCulture)},asetpts=PTS-STARTPTS";
    filters.Add($"[{input}:a]aresample=24000,aformat=channel_layouts=mono,{align},volume={Num(game.Volume)}[game]");
    input++;
}
if (labels.Count > 0 && game is not null)
{
    filters.Add($"{string.Concat(labels)}amix=inputs={labels.Count}:normalize=0:dropout_transition=0,apad[nar]");
    filters.Add("[nar]asplit=2[nar1][key]");
    filters.Add("[game][key]sidechaincompress=threshold=0.02:ratio=8:attack=20:release=400[duck]");
    filters.Add("[duck][nar1]amix=inputs=2:normalize=0:dropout_transition=0[aout]");
}
else if (game is not null) filters.Add("[game]apad[aout]");
else if (labels.Count > 0) filters.Add($"{string.Concat(labels)}amix=...,apad[aout]");   // 기존
```

- **검증**: `FfmpegTests`
  - 게임 소리가 있을 때: 마지막 입력이 `game.wav`이고, `adelay=1500|1500`(오프셋 1.5초)이 들어갑니다.
  - 오프셋이 -0.3초면 `atrim=start=0.3`이 들어갑니다.
  - `sidechaincompress` 체인과 `volume=0.8`이 들어갑니다.
  - 게임 소리만 있을 때 `[game]apad[aout]`가 들어갑니다.
  - 기존 테스트(게임 소리 없음)는 그대로 통과합니다.
  - 실제 ffmpeg로 합성 입력(사인파 game.wav와 안내 WAV)을 넣어 실행하면 exit 0이고, 안내 구간에서 게임 소리 음량이 줄어듭니다(volumedetect).
- **선행 단위**: 없음

## G3. 프로세스 루프백 인터롭 (`ProcessLoopback.cs`)
- **대상**: 새 파일. COM 인터페이스 선언, `ActivateAsync(int pid)` → `IAudioClient`, 캡처 루프
- **코드 초안**:
```csharp
[DllImport("Mmdevapi.dll", ExactSpelling = true, PreserveSig = true)]
private static extern int ActivateAudioInterfaceAsync([MarshalAs(UnmanagedType.LPWStr)] string deviceInterfacePath,
    ref Guid riid, IntPtr activationParams, IActivateAudioInterfaceCompletionHandler handler,
    out IActivateAudioInterfaceAsyncOperation op);

[StructLayout(LayoutKind.Sequential)]
private struct AudioClientActivationParams { public int ActivationType; public int TargetProcessId; public int ProcessLoopbackMode; }
// ActivationType 1 = PROCESS_LOOPBACK, ProcessLoopbackMode 0 = INCLUDE_TARGET_PROCESS_TREE

// PROPVARIANT(VT_BLOB=0x41): vt(2) + reserved(6) + blob{cbSize(4), pad(4), pBlobData(8)} = 24 bytes(x64)
IntPtr p = Marshal.AllocHGlobal(Marshal.SizeOf<AudioClientActivationParams>());
Marshal.StructureToPtr(new AudioClientActivationParams { ActivationType = 1, TargetProcessId = pid }, p, false);
IntPtr pv = Marshal.AllocHGlobal(24); /* vt=0x41, cbSize, pBlobData=p */

[ComVisible(true)]
private sealed class Completion : IActivateAudioInterfaceCompletionHandler, IAgileObject
{
    public readonly TaskCompletionSource<object> Done = new(TaskCreationOptions.RunContinuationsAsynchronously);
    public void ActivateCompleted(IActivateAudioInterfaceAsyncOperation op)
    {
        op.GetActivateResult(out int hr, out object unk);
        if (hr < 0) Done.TrySetException(new COMException("activate_failed", hr)); else Done.TrySetResult(unk);
    }
}

// Initialize: AUDCLNT_STREAMFLAGS_LOOPBACK(0x20000) | EVENTCALLBACK(0x40000) | AUTOCONVERTPCM(0x80000000) | SRC_DEFAULT_QUALITY(0x08000000)
client.Initialize(0 /*SHARED*/, flags, 2_000_000 /*200ms*/, 0, ref format, IntPtr.Zero);
```
  - 캡처 스레드: `WaitForSingleObject(event, 100)`, 이어서 `GetNextPacketSize`, `GetBuffer(out data, out frames, out flags, …)`, `sink.Write(data or zeros, frames)`, `ReleaseBuffer(frames)` 순서로 반복합니다.
  - `IAudioCaptureSource` 인터페이스(`Start`, `Read(Action<ReadOnlySpan<byte>,int>)`, `Stop`)로 감싸서 G4가 가짜 소스로 테스트할 수 있게 합니다.
  - 실패는 `GameAudioResult(bool Ok, string? Error)`로 돌려줍니다. 예외를 밖으로 던지지 않습니다.
- **검증**:
  - 빌드가 성공합니다.
  - 장치가 없는 지금 환경에서 KSP PID로 활성화를 시도하면 `activate_failed: 0x...` 또는 `initialize_failed`가 반환되고 예외가 나지 않습니다(실제 실행으로 확인).
  - 프로세스가 없으면 `game_process_not_found`가 반환됩니다.
- **선행 단위**: 없음

## G4. 녹음기와 무음 채움 (`GameAudioRecorder.cs`)
- **대상**: `IGameAudioRecorder`(`Start(string path, string process)` → `GameAudioResult`, `StartedAt`, `StopAsync()`), 구현 `GameAudioRecorder(IClock, Func<int, IAudioCaptureSource?>)`, `WavWriter`
- **코드 초안**:
```csharp
private void Pump()
{
    while (!_stop)
    {
        _source.Read((data, frames) => _wav.Write(data));            // 들어온 패킷
        long expected = (long)((clock.Now - StartedAt) * Rate);
        long missing = expected - _wav.Frames - Rate / 10;            // 0.1초 허용 오차
        if (missing > 0) _wav.WriteSilence(missing);                  // KSP가 조용한 구간
        Thread.Sleep(10);
    }
    long final = (long)((clock.Now - StartedAt) * Rate);
    if (final > _wav.Frames) _wav.WriteSilence(final - _wav.Frames);
    _wav.Complete();                                                  // RIFF/data 크기 확정
}
```
- **검증**: `GameAudioRecorderTests`
  - 가짜 소스는 0.5초 동안만 데이터를 주고, 시계는 2초까지 진행합니다. 이때 WAV 길이가 2.0초(±0.1초)이고, 0.5초 이후 구간은 0으로 채워지는지 확인합니다.
  - 시작에 실패하면 파일을 만들지 않습니다.
- **선행 단위**: G3(인터페이스)

## G5. 세션 연동
- **대상**: `BroadcastSession`(생성자에 `IGameAudioRecorder?` 추가, Start/Stop/Dispose/Status/Compose), `Program` DI, `BroadcastToolsTests`의 가짜 녹음기
- **코드 초안**:
```csharp
// StartAsync, _zero = await _recorder.StartAsync(...) 직후
if (settings.GameAudio && gameAudio is not null)
{
    GameAudioResult r = gameAudio.Start(Path.Combine(_dir, "game.wav"), settings.GameProcess);
    _gameAudio = r.Ok; _gameAudioError = r.Error;
    if (!r.Ok) logger.LogWarning("Game audio not recorded: {Error}", r.Error);
}

// StopAsync: int code = await _recorder!.StopAsync(); 다음
if (_gameAudio) await gameAudio!.StopAsync();

// ComposeAsync
GameTrack? game = _gameAudio ? new GameTrack("game.wav", gameAudio!.StartedAt - _zero, settings.GameVolume) : null;
var (args, filter) = FfmpegArgs.Compose(cues, game);
```
- **검증**: `BroadcastToolsTests`
  - 가짜 녹음기를 쓰면 녹음 시작이 첫 프레임 이후, 녹음 중지가 화면 녹화 중지 이후에 호출됩니다.
  - 합성 인수에 `game.wav`가 들어갑니다.
  - 시작에 실패해도 `ignited: true`이고, 상태에 `gameAudio: false`와 실패 이유가 나옵니다.
  - `GameAudio=false`면 녹음을 호출하지 않습니다.
  - 전체 테스트가 통과합니다.
- **선행 단위**: G1, G2, G4

## G6. 실제 녹음 검증 (사운드 장치 연결 후)
- **대상**: 코드 변경 없음. ReadMe와 설계 문서에 결과를 기록합니다.
- **검증**:
  1. 재배포하고 Claude를 재시작합니다.
  2. KSP가 실행 중인 상태에서 실게임 중계를 한 번 합니다.
  3. `game.wav`의 길이가 `raw.mkv`와 ±0.2초 안인지, 음량이 0이 아닌지 확인합니다.
  4. `final.mp4`에서 확인합니다:
     - 점화 직후 엔진 소리가 들어 있는지
     - 카운트다운 숫자 구간에서 게임 소리가 낮아지는지(volumedetect)
     - 받아쓰기로 카운트다운이 여전히 정확한지
  5. 사용자가 직접 들어 보고 덕킹 값을 조정할지 정합니다.
- **선행 단위**: G1~G5
