## 단위 1: `attitude_drift` 판정과 설정 키 (설계 1·2·4)

### 대상

- `src/KspBridge.Logic/Flight/FlightMonitor.cs`: 필드, `Tick`, `ResetStep`, `EndPlan`, `Settings`, `Effective`
- `src/KspBridge.Logic/Routes.cs`: `0.2.62`

### 코드 초안

```csharp
// fields
private static double _drift;            // attitude_drift: accumulated angle the nose moved away from the target by itself (deg)
private static Vector3d? _driftPrev;     // nose direction at the last judged tick (null = none: the next tick adds nothing)

// Tick, after Accumulate(ref _wasteFor, ...) and before the Set calls
// attitude_drift: no thrust (or a forced land start still turning, thrust cut by cos) with a commanded attitude.
// Paused (kept as is, previous nose dropped) on rails, while staging and when the error is not known.
// No commanded attitude is checked first (구현 검토 R5-3-B-1 반영): its attitude_error is NaN too, but it ends the episode.
bool driftArmed = !thrusting || cmd.Aligning;
bool driftPause = v.packed || t.Str["staging"] != "none" || double.IsNaN(err);
string driftLevel = _level.TryGetValue("attitude_drift", out string dl) ? dl : null;   // unchanged while paused
if (!cmd.Attitude.HasValue)
{
    ResetDrift();
    driftLevel = null;
}
else if (driftPause)
{
    _driftPrev = null;
}
else if (!driftArmed)
{
    ResetDrift();
    driftLevel = null;
}
else
{
    Vector3d dir = cmd.Attitude.Value.Direction(v);
    Vector3d nose = v.ReferenceTransform.up;
    if (_driftPrev.HasValue)   // change of the nose against the current target only: target moves add nothing
    {
        _drift = Math.Max(0, _drift + Vector3d.Angle(nose, dir) - Vector3d.Angle(_driftPrev.Value, dir));
    }
    _driftPrev = nose;
    if (err > s.DriftErrorDeg && _drift >= s.DriftGrowthDeg)
    {
        driftLevel = "warn";
    }
    else if (err <= s.DriftErrorDeg)
    {
        if (driftLevel != null)
        {
            ResetDrift();   // cleared: a new episode accumulates from 0
        }
        driftLevel = null;
    }
    // else: above the limit, not (or no longer) accumulated: keep the current level until it comes back under
}

// with the other warn-only items
Set("attitude_drift", driftLevel, err, s.DriftErrorDeg, null);

private static void ResetDrift()
{
    _drift = 0;
    _driftPrev = null;
}

// ResetStep and EndPlan: also
ResetDrift();

// Settings.Keys: + "drift_error_deg", "drift_growth_deg"
// Settings: public double? DriftErrorDeg, DriftGrowthDeg;
DriftErrorDeg = Num(o, "drift_error_deg", path, 1, 180),
DriftGrowthDeg = Num(o, "drift_growth_deg", path, 1, 180),

// Effective: public double DriftErrorDeg, DriftGrowthDeg;
DriftErrorDeg = step?.DriftErrorDeg ?? plan?.DriftErrorDeg ?? 30,
DriftGrowthDeg = step?.DriftGrowthDeg ?? plan?.DriftGrowthDeg ?? 20,
```

- 켜진 뒤 오차가 한계 위에 머무는 동안(예: 기수가 아래로 고정되어 오차가 165~175°로 오르내림)은 경고를 유지한다. 누적값이 줄어든다고 꺼지지 않게, 해제는 `err ≤ drift_error_deg`이거나 `armed`가 풀릴 때만 한다(설계 1 "해제").
- `driftPause` 중에는 수준과 누적값을 그대로 두고 직전 기수만 버린다(정지 전후의 기수 변화를 한 틱으로 세지 않음). `Enabled` false면 `Tick`이 앞에서 돌아가므로 판정하지 않는다.
- `thrusting`은 기존 정의(`throttle > 0 && thrust > 0`)를 그대로 쓴다. `cmd.Aligning`은 land 강제 시작 뒤 첫 정렬 전에만 참이다(`LandMode.Update`).
- `Vector3d`·`AttitudeTarget.Direction`은 `flipped` 판정(`cmdAoa`)이 이미 같은 방식으로 쓴다.

### 검증

- `dotnet build src/KspBridge.Logic` 경고·오류 0. `reload_mod` 0.2.62.
- StabS 홉 → `land`(실측 1과 같은 계획): 충돌 전 `monitor_alert attitude_drift warn`(`value` > 30), `plan_aborted monitor` 없음. 판정 기준은 "충돌 전 경고"이며, 경고 MET·`value`와 연소 시작(`burn start`) 전후 여부는 기록만 한다(0058 설계 3).
- StabL 홉 → `land`: `attitude_drift` 이벤트 없이 `landed`.
- 단계 안 목표 전환 대조: StabL `attitude` 피치 90 스로틀 1 → 원지점 1,500 m → `coast reference surface_prograde`, `warp false`, `until` 하강 속도 30 m/s 초과 → `land`. 정점에서 목표가 약 180° 뒤집혀도 `attitude_drift` 없음, `landed`.
- 기존 상승 회귀: StabS `gravity_turn`(80 km) → `coast` → `circularize` → `attitude_drift` 없음, 다른 감시 이벤트는 0051 실측과 같은 수준.
- 설정 키: 계획 수준 `monitor {drift_error_deg 200}` → `invalid_plan`. 계획 수준 `monitor {drift_error_deg 40, drift_growth_deg 10}`과 단계 수준 `monitor {drift_growth_deg 15}` 동시 접수.

### 초안

- `submit_flight_plan`: `... and only alerts on thrust_waste (...), oscillation (...)` 다음에 다음 문구를 넣는다.
  ```text
  and attitude_drift (no thrust, or land still turning after a forced start, with a commanded attitude: attitude_error > drift_error_deg 30 while the nose has itself moved drift_growth_deg 20 away from the target, target moves not counted, since thrust stopped, the step began or the last clear; kept while staging, on rails or with no attitude_error; cleared once back under drift_error_deg)
  ```
- `get_flight_events`: `monitor_alert {kind flipped|control_lost|overheat|thrust_waste|oscillation|attitude_drift, ...}`.
- ReadMe "경고만" 목록에 다음 항목을 더한다.
  ```text
  `attitude_drift`(추력 없이, 또는 land 강제 시작 뒤 정렬 중에 명령 자세가 있을 때 `attitude_error`가 `drift_error_deg` 30°를 넘고, 기수가 스스로 목표에서 `drift_growth_deg` 20° 이상 벌어짐. 목표가 움직인 만큼은 세지 않음. 추력이 멈추거나 단계가 시작되거나 해제된 뒤부터 셈. 스테이징·레일·오차 없음 동안은 유지. 한계 아래로 돌아오면 해제)
  ```
