# KspBridge 비행 안전 하네스 개발 계획 — 묶음 B (이상 감지·궤도 기준 자세·노드 실행)

선행: [0035-비행안전하네스-방안.md](0035-비행안전하네스-방안.md) · [0038-비행안전하네스-설계.md](0038-비행안전하네스-설계.md)

## 회귀 기록 (2026-11-08 독립 검토)
- 노드 실행: (1) 점화 시각을 1초 넘기도록 점화하지 못하면 늦게 연소하지 않고 `aborted`(`not_aligned_in_time`/`missed_ignition`). 점화는 오차 < 4°일 때만. 시간 가속 중에는 시작을 거부. (2) 시작부터 스로틀을 0으로 소유하고, 마지막으로 넣은 값과 다르면(다른 도구가 `set_throttle`) `overridden`. 종료 때는 자기가 소유한 스로틀·자세만 풉니다(사용자 스로틀 유지 보존). `ThrottleLock.Value` 추가.
- `control_lost`: 브리지 자세 유지는 항상 감시, stock SAS만 켠 경우는 LANDED/SPLASHED/PRELAUNCH에서 제외(지면 접촉으로 SAS가 한계에 붙는 로버·활주로).
- `flameout`: 대기 시작 때 연소 중이던 엔진 각각을 기준으로 판정(이미 꺼진 엔진이 있어도 이후 다른 엔진 연소 종료를 감지).
- `set_attitude`: 비-surface 프레임에 `roll`/`pitch`/`heading`을 주면 App이 버리지 않고 전달해 모드가 400으로 거부.
- `execute_node` 설명: 연료 고갈 시 트리거 스테이징보다 먼저 중단되므로 단별로 노드를 나누라고 명시.
- 시험 비행 3(2026-11-08)으로 확인: 사용자 스로틀 1에서 시작 즉시 0, 실행 중 사용자 `set_throttle` → `overridden`·사용자 잠금 유지, 정렬 지연 → `not_aligned_in_time`(연소 없음), 연료 고갈 → `flameout`(엔진 이름). 시간 가속 없이 비행, 분리 후 낙하산 트리거로 착륙·회수.

## 회귀 기록 (2026-11-08 구현·시험 비행 1)
- 시험 비행 1에서 180° 회전(prograde → retrograde) 중 제어기가 목표를 약 100° 지나쳐 흔들렸고, 각도 기준 `attitude_error`가 이를 이상으로 잡았습니다. 각도 오차는 증상일 뿐이라 정상 회전·진동을 오검지하고 기체마다 기준값이 달라집니다.
- 사용자 결정: 판정을 **조종 응답**으로 바꿉니다. 최종 조종 입력(`vessel.ctrlState`)이 한계 근처(≥ 0.9)로 2.5초 이어지는데 그 축의 각가속도가 입력 방향으로 나오지 않으면 `control_lost`. 이름도 `attitude_error` → `control_lost`.
- 제어기 과도 회전(지나침)은 별개 문제로 이 묶음 범위 밖입니다.
- `attitude_after_warp`의 `over_limit`(15°)은 기록용 표시라 그대로 둡니다.

## 회귀 기록 (2026-11-08 검토)
- `attitude_error`: 오차 15° 초과가 3초 지속이면 정상적인 큰 회전에서도 잘못 감지됩니다. 최근 3초 동안 오차가 1° 이상 줄지 않을 때만 이상으로 봅니다(단위 2).
- 노드 실행: 정렬(2°)과 회전 정지(각속도 < 0.01 rad/s)가 끝난 뒤에만 가속을 시작합니다. 노드 연소 방향은 관성 기준이고 레일 가속은 관성 자세를 유지하므로, 가속 뒤에도 어긋나지 않게 설계에서 막습니다(단위 5). 가정은 인게임에서 확인합니다.

- Logic은 단위 테스트가 없어 단위마다 `dotnet build`와 인게임 확인으로 검증합니다.
- 단위 1~5의 인게임 확인은 MCP 도구가 아직 새 인수를 모르므로 모드 HTTP(`http://127.0.0.1:8085`)를 `curl`로 직접 부릅니다. 단위 6에서 MCP 도구로 다시 확인합니다.
- 각 단위가 끝나면 `reload_mod`로 올립니다. 버전은 단위 6에서 한 번만 올립니다.

```csharp
public sealed class Condition
{
    private string _field;
    private Func<object, bool> _test;
    private List<Condition> _children;
    private bool _all;

    public static Condition Parse(Dictionary<string, object> node, int depth = 0)
    {
        if (depth > 4) throw ApiException.BadRequest("condition nesting is limited to 4 levels");
        RequestBody b = new RequestBody(node);
        bool all = b.Has("all"), any = b.Has("any"), single = b.Has("field");
        if ((all ? 1 : 0) + (any ? 1 : 0) + (single ? 1 : 0) != 1)
            throw ApiException.BadRequest("a condition has exactly one of field, all, any");
        if (single)
        {
            string field = b.GetString("field");
            return new Condition { _field = field, _test = FlightFields.BuildTest(field, b.GetString("op"), b) };
        }
        List<object> items = b.GetList(all ? "all" : "any");
        if (items.Count == 0) throw ApiException.BadRequest((all ? "all" : "any") + " must not be empty");
        return new Condition
        {
            _all = all,
            _children = items.Select(o => Parse(o as Dictionary<string, object>
                ?? throw ApiException.BadRequest("each condition must be an object"), depth + 1)).ToList(),
        };
    }

    public bool Evaluate(Vessel v, Dictionary<string, object> values)
    {
        if (_field != null)
        {
            object value = FlightFields.Read(v, _field);
            values[_field] = value;
            return _test(value);
        }
        // Evaluate every child so values holds all fields (no short-circuit).
        List<bool> r = _children.Select(c => c.Evaluate(v, values)).ToList();
        return _all ? r.All(x => x) : r.Any(x => x);
    }

    public bool IsSingle => _field != null;
    public string SingleField => _field;
}
```

- `TriggerManager.Add`: `when`을 `Condition.Parse(when)`으로 바꾸고 `Trigger.Field`/`Test` 대신 `Trigger.Condition`을 둡니다. 내부 트리거(`AddInternal`, `Reader`)는 지금 경로를 유지합니다.

## 단위 2. 이상 감시 `AnomalyMonitor`·`abort_on`
- **대상**: `Flight/AnomalyMonitor.cs`(새 파일), `BridgeLogic.cs`(Hook·FixedUpdate·해제), `Handlers/WaitHandler.cs`
- **코드 초안**:

```csharp
public static class AnomalyMonitor
{
    public const double AttitudeErrorDeg = 15, AttitudeErrorSeconds = 3, ConvergeDeg = 1;
    private static readonly Dictionary<Guid, int> _partsDied = new Dictionary<Guid, int>();
    private static readonly Queue<(float t, double err)> _errHistory = new Queue<(float, double)>();
    private static bool _attitudeBad;

    public static void Hook() => GameEvents.onPartDie.Add(OnPartDie);
    public static void Unhook() => GameEvents.onPartDie.Remove(OnPartDie);

    private static void OnPartDie(Part p)
    {
        if (p?.vessel == null) return;
        _partsDied.TryGetValue(p.vessel.id, out int n);
        _partsDied[p.vessel.id] = n + 1;
    }

    public static int PartsDied(Guid id) => _partsDied.TryGetValue(id, out int n) ? n : 0;

    public static void FixedUpdate()
    {
        Vessel v = FlightGlobals.ActiveVessel;
        double? err = v == null ? null : AttitudeController.ErrorDeg(v);
        float now = Time.realtimeSinceStartup;
        if (!err.HasValue || err.Value <= AttitudeErrorDeg) { _errHistory.Clear(); _attitudeBad = false; return; }
        _errHistory.Enqueue((now, err.Value));
        while (_errHistory.Count > 1 && now - _errHistory.Peek().t > AttitudeErrorSeconds) _errHistory.Dequeue();
        // Over the limit for the whole window and not converging: a big but progressing slew (e.g. 180° to retrograde) passes.
        (float t0, double e0) = _errHistory.Peek();
        _attitudeBad = now - t0 >= AttitudeErrorSeconds * 0.95f && e0 - err.Value < ConvergeDeg;
    }

    public static bool AttitudeBad => _attitudeBad;
}
```

- `WaitHandler`: `abort_on` 기본 `["part_lost","attitude_error"]`, 허용 값 외는 400. 시작 시 스냅숏(`PartsDied(id)`, `FlightFields.AnyFlameout(v)`)을 잡고 `Check`에서 비교합니다.

## 단위 3. 자세 기준 프레임·받음각 제한
- **대상**: `Attitude/AttitudeController.cs`(`Set`, `TargetDirection`, `Describe`), `Handlers/AttitudeHandler.cs`
- **코드 초안**:

```csharp
private static Vector3? FrameDirection(Vessel v)
{
    Vector3 obt = v.obt_velocity, srf = v.srf_velocity;
    Vector3 up = (v.CoMD - v.mainBody.position).normalized;
    Vector3 normal = Vector3.Cross(obt, up).normalized;   // orbit normal (navball "normal")
    switch (_frame)
    {
        case "prograde": return obt.magnitude < 0.5f ? (Vector3?)null : obt.normalized;
        case "retrograde": return obt.magnitude < 0.5f ? (Vector3?)null : -obt.normalized;
        case "normal": return normal;
        case "antinormal": return -normal;
        case "radial_out": return Vector3.Cross(normal, obt).normalized;
        case "radial_in": return -Vector3.Cross(normal, obt).normalized;
        case "surface_prograde": return srf.magnitude < 0.5f ? (Vector3?)null : srf.normalized;
        case "surface_retrograde": return srf.magnitude < 0.5f ? (Vector3?)null : -srf.normalized;
        case "node":
            ManeuverNode n = v.patchedConicSolver?.maneuverNodes.FirstOrDefault();
            return n == null ? (Vector3?)null : (Vector3)n.GetBurnVector(v.orbit).normalized;
    }
    return null;
}

private static Vector3 TargetDirection(Vessel v)
{
    Vector3 dir;
    if (_frame == "surface")
        dir = SurfaceFrame.SurfaceRotation(v) * (Quaternion.Euler(-(float)_pitch, (float)_heading, 0) * Vector3.forward);
    else
    {
        Vector3? f = FrameDirection(v);
        _frameInvalid = f.HasValue ? null : "reference direction unavailable";
        dir = f.HasValue ? ApplyOffsets(v, f.Value) : _lastDirection;
    }
    dir = LimitAoa(v, dir);
    _lastDirection = dir;
    return dir;
}

private static Vector3 LimitAoa(Vessel v, Vector3 dir)
{
    _aoaLimited = false;
    if (!_maxAoa.HasValue || v.dynamicPressurekPa < 1.0 || v.srf_velocity.magnitude < 0.5f) return dir;
    Vector3 vel = v.srf_velocity.normalized;
    float ang = Vector3.Angle(vel, dir);
    if (ang <= _maxAoa.Value) return dir;
    _aoaLimited = true;
    return Vector3.RotateTowards(vel, dir, (float)_maxAoa.Value * Mathf.Deg2Rad, 0f);
}
```

- `ApplyOffsets`: `pitch_offset`은 기준 방향과 지역 위쪽(`up`)에 수직인 축(`Cross(dir, up)`)으로 돌려 기수를 올리고 내립니다. `yaw_offset`은 `up` 축으로 돌립니다. 기준 방향이 `up`과 거의 평행(5° 이내, 예: `radial_out`)이면 pitch 축을 궤도 법선으로 대신합니다(검토 회귀: 설계의 "법선 축" 정의는 `normal` 프레임에서 회전이 안 되므로 바꿈).
- `Set` 시그니처에 `frame`, `pitchOffset`, `yawOffset`, `maxAoa`를 더합니다. `frame != "surface"`인데 `pitch`/`heading`이 오면 400(`AttitudeHandler`에서 판정). `roll`은 현재 경로(`SurfaceFrame.TargetRotation`) 그대로 두되, `surface` 외 프레임에서는 받지 않습니다(400).
- **검증**: `dotnet build`. 인게임: 궤도 기체로 `curl /api/attitude`에 `frame=prograde`, `retrograde`, `normal` 각각 → 20초 뒤 `GET` 자세 `error_deg < 3`. 대기 비행 중 `surface_prograde` + `max_aoa_deg=5` → `aoa_limited` 로그와 받음각 ≤ 5°. 기존 `surface` 호출(MCP `set_attitude`)이 그대로 동작
- **선행 단위**: 없음

## 단위 5. 노드 실행 `NodeExecutor`
- **대상**: `Flight/NodeExecutor.cs`(새 파일), `Handlers/NodeHandler.cs`(`Execute`, `Cancel`), `Routes.cs`(`POST /api/node/execute`, `/api/node/cancel`), `Flight/FlightFields.cs`(`node_exec`, `node_dv_remaining`), `BridgeLogic.cs`(FixedUpdate·해제)
- **코드 초안**:

```csharp
public static class NodeExecutor
{
    public static string State = "idle";       // idle | aligning | waiting | burning | done | aborted
    public static string Reason;
    private static Vessel _v; private static ManeuverNode _node; private static Vector3d _dir0;
    private static double _igniteUt, _nodeUt, _nodeDv, _tolerance; private static bool _warp, _remove, _warped;

    public static Dictionary<string, object> Start(Vessel v, double tolerance, bool warp, bool remove)
    {
        ManeuverNode n = v.patchedConicSolver?.maneuverNodes.FirstOrDefault() ?? throw ApiException.BadRequest("no maneuver node");
        double dv = n.GetBurnVector(v.orbit).magnitude;
        Burn(v, dv, out double burnTime, out double stageDv);
        Burn(v, dv / 2, out double halfTime, out _);
        // ... set fields, State = "aligning", AttitudeController.Set(v, "own", frame: "node")
        List<string> warnings = new List<string>();
        if (stageDv < dv) warnings.Add("current stage delta-v " + stageDv.ToString("F0") + " < node " + dv.ToString("F0") + " m/s (no auto staging)");
        return new Dictionary<string, object> { ["node_dv"] = dv, ["burn_time"] = burnTime, ["half_dv_time"] = halfTime, ["ignite_ut"] = n.UT - halfTime, ["stage_dv"] = stageDv, ["warnings"] = warnings };
    }

    /// <summary>Rocket equation burn time at full throttle of the current stage's active engines.</summary>
    private static void Burn(Vessel v, double dv, out double seconds, out double stageDv)
    {
        List<ModuleEngines> eng = v.parts.SelectMany(p => p.FindModulesImplementing<ModuleEngines>()).Where(e => e.EngineIgnited && e.isOperational).ToList();
        double thrust = eng.Sum(e => (double)e.maxThrust * e.thrustPercentage / 100.0);
        double flow = eng.Sum(e => (double)e.maxThrust * e.thrustPercentage / 100.0 / Math.Max(1e-3, e.atmosphereCurve.Evaluate(0f)));
        if (thrust <= 0) throw ApiException.BadRequest("no active engine (stage first)");
        double ve = thrust / flow * G0, m0 = v.totalMass;
        double m1 = m0 * Math.Exp(-dv / ve);
        seconds = (m0 - m1) / (thrust / ve);
        stageDv = v.VesselDeltaV?.GetStage(v.currentStage)?.deltaVinVac ?? double.NaN;   // 활성 단, 없으면 NaN → 경고 생략
    }

    public static void FixedUpdate()
    {
        if (State is "idle" or "done" or "aborted") return;
        if (FlightGlobals.ActiveVessel != _v) { Abort("vessel_changed"); return; }
        if (!_v.patchedConicSolver.maneuverNodes.Contains(_node)) { Abort("node_removed"); return; }
        if (Math.Abs(_node.UT - _nodeUt) > 0.5 || (State != "burning" && Math.Abs(_node.DeltaV.magnitude - _nodeDv) > 0.5)) { Abort("node_changed"); return; }
        Vector3d burn = _node.GetBurnVector(_v.orbit);
        double ut = Planetarium.GetUniversalTime();
        switch (State)
        {
            case "aligning":
                // Aligned and still before any warp: the node burn vector is inertial and rails warp keeps the inertial
                // attitude, so the vessel is still on the node direction when warp ends.
                if (AttitudeController.ErrorDeg(_v) < 2 && _v.angularVelocity.magnitude < 0.01f) State = "waiting";
                break;
            case "waiting":
                if (_warp && !_warped && _igniteUt - ut > 60) { TimeWarp.fetch.WarpTo(_igniteUt - 30); _warped = true; }
                if (ut >= _igniteUt && TimeWarp.CurrentRate <= 1.01f) { State = "burning"; _dir0 = burn; }
                break;
            case "burning":
                if (burn.magnitude < _tolerance || Vector3d.Dot(burn, _dir0) < 0) { Finish(); break; }
                if (FlightFields.StageFlameout(_v)) { Abort("flameout"); break; }
                double accel = Prediction.Get(_v).MaxAccel;
                ThrottleLock.Set(_v, (float)Math.Max(0.05, Math.Min(1.0, burn.magnitude / Math.Max(1e-3, accel))));
                break;
        }
    }
    // Finish(): ThrottleLock.Set(_v, 0); AttitudeController.Release(); if (_remove) _node.RemoveSelf(); State = "done"
    // Abort(r):  ThrottleLock.Set(_v, 0) (vessel alive); AttitudeController.Release(); State = "aborted"; Reason = r
}
```

- 실행 중 다른 도구가 자세(`set_attitude`, `release_attitude`)나 스로틀을 바꾸면 매 프레임 `AttitudeController`의 프레임이 `node`가 아니게 되므로 `aborted: overridden`으로 끝냅니다(검토 회귀).
- 연소 중 노드 Δv는 줄어드는 것이 정상이므로 `node_changed`의 Δv 비교는 `burning` 전까지만 합니다.
- 상태 전환마다 `FlightRecorder`에 `node_exec` 이벤트를 남깁니다.
- `FlightFields`: `node_exec` → `NodeExecutor.State`(문자열, `==`만), `node_dv_remaining` → 실행 중이면 `burn.magnitude`, 아니면 첫 노드 Δv(숫자).
- `reload_mod`·장면 전환 해제 목록에 `NodeExecutor.Abort("reloaded")`를 넣습니다.
- **검증**: `dotnet build`. 인게임: 원지점 근처 궤도 기체에 순환화 노드(`add_maneuver_node`) → `curl /api/node/execute` → 계획 응답 확인 → 레일 가속이 끝난 직후 `node_exec` 이벤트·자세 `error_deg` < 2°(가속 뒤 어긋나지 않는다는 설계 가정 확인; 어긋나면 설계 회귀) → `wait_until node_exec == done`(필요하면 여러 번) → 남은 Δv < 0.1, 근지점이 노드 예측과 1% 이내. `cancel`은 `waiting` 중 호출해 `aborted: cancelled`
- **선행 단위**: 3(`frame=node`)
