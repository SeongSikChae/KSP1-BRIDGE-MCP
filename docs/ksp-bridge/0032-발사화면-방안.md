# KspBridge 발사대 화면 셋팅 방안

## 문제·목표
- 발사대에서 로켓을 준비할 때마다 필요한 화면을 손으로 켜야 합니다.
- 목표: MCP 도구 하나로 아래 세 가지를 한 번에 셋팅합니다.
  1. **우측 상단**: 자원 창(Resources 앱)
  2. **Δv 정보**: 스테이지별 Δv, TWR, ISP, 연소 시간과 전체 Δv
  3. **좌측 하단**: 메뉴버 모드(Ap/Pe가 나오는 궤도 정보)

## 확인한 게임 API (Assembly-CSharp 디컴파일)
| 대상 | API |
|---|---|
| 자원 창 | `KSP.UI.Screens.ResourceDisplay.Instance.appLauncherButton` (`UIApp`의 앱 런처 버튼) |
| 스테이지 Δv 상세 | `StageManager.Instance.EnableDeltaVTotal/EnableDeltaVHeadings/EnableInfoPanels(true)`, `ToggleInfoPanels(true)` |
| 메뉴버 모드 | `FlightUIModeController.Instance.SetMode(FlightUIMode.MANEUVER_INFO)` |

## 검토한 대안
| 대안 | 판단 |
|---|---|
| **게임 UI를 API로 켜기** | **채택**. 게임이 계산한 값을 게임 화면 그대로 보여 줍니다 |
| 자체 IMGUI 패널 | 게임 화면과 중복되고 손이 많이 갑니다 |
| 키 입력/클릭 흉내 | 해상도와 UI 배율에 따라 깨집니다 |

### Δv 표시 방법 (회귀 후 재검토)
| 대안 | 판단 |
|---|---|
| 스테이지 창 강제 펼침 + 상세 패널 | **폐기**. 인게임 확인 결과 스테이지 모드 하단 패널이 함께 올라와 메뉴버 패널을 덮었습니다 |
| 스테이지 창은 펴고 하단 패널만 숨김 | 하단 패널 오브젝트를 prefab에서 찾아야 해서 불확실합니다 |
| Δv 앱 열기 | **폐기**. 인게임 확인 결과 Δv 앱이 우측 위 자원 창을 덮었습니다 |
| **메뉴버 모드에서 스테이지 상세 패널만 켜기** | **채택**. 메뉴버 모드에서도 좌측 스테이지 창이 보입니다(인게임 확인). 스테이지 영역 강제 펼침만 하지 않으면 하단 패널이 올라오지 않습니다 |

## 채택 방안
1. **새 MCP 도구 `setup_launch_ui`**
   - 비행 장면에서만 동작합니다. 그 밖의 장면이면 오류를 돌려줍니다.
   - 발사대(PRELAUNCH)가 아니어도 비행 중이면 적용합니다(발사 전 준비가 주 용도입니다).
2. **적용 순서**
   1. 메뉴버 모드로 바꿉니다(좌측 하단 Ap/Pe). 메뉴버 모드에서도 좌측 스테이지 창은 그대로 보입니다.
   2. 좌측 스테이지 창에 전체 Δv·제목·상세 패널(비추력, 추력, 추중비, 질량, 연소 시간)을 켭니다. 스테이지 영역 전환(`stagingQuadrant`)은 하지 않습니다.
   3. 자원 창이 닫혀 있으면 엽니다.
3. **결과 보고**: 항목마다 적용했는지(`maneuver_mode`, `deltav_info`, `resources`), 실패하면 그 이유를 돌려줍니다. 한 항목이 실패해도 나머지는 계속합니다.

## 결정 (2026-11-08 사용자)
- 적용 시점: MCP 도구로 호출할 때만 적용합니다(발사 시 자동 적용 안 함)
- 절차: 방안→설계→개발→검토→구현 전체 절차
- (회귀 1) 스테이지 영역 강제 펼침은 하단 패널이 메뉴버 패널을 덮어 폐기합니다
- (회귀 2) Δv 앱은 자원 창을 덮어 폐기합니다. 메뉴버 모드에서 좌측 스테이지 상세 패널만 켭니다

## 비범위
- 발사 시 자동 적용
- 자체 UI 패널, 다른 UI 요소(내비볼, 승무원 초상화) 변경, 스테이지 영역 강제 펼침
- 셋팅 상태 저장·복원

## 위험
- 스테이지 상세 패널이 길어지면 좌측 하단 메뉴버 패널과 세로로 맞닿을 수 있습니다. 인게임 화면으로 확인합니다.
