# KspBridge 커리어 1단계 — 방안

선행: `0001-비행제어-방안.md` ~ `0003-비행제어-개발.md` (비행제어 MVP, U6 기동 노드 게임 검증만 미완)

## 문제·목표
비행제어 MVP로는 스로틀·스테이징·SAS만 가능하고 조향이 없어 궤도에 오를 수 없다. 사용자는 현재 **커리어 세이브**(`saves/새 게임`: 자금 23,743, 과학 0, 제안된 탐사 계약 4개, 기술 `start`만, 추적 기지 레벨 낮아 기동 노드 불가)를 Claude가 직접 진행하길 원한다.
목표: Claude가 사용자 손을 거의 빌리지 않고 커리어 초반 계약(첫 발사, 과학 수집, 고도·대기권 탈출, 궤도 진입)을 수행할 수 있는 도구를 만든다.

## 진행 방식 (사용자 결정)
- **1단계**에 아래 4개 묶음을 모두 넣는다.
- 그 이후는 고정 로드맵 없이 **다음에 깰 계약 하나에 필요한 기능만** 그때그때 추가한다. 각 추가는 work-process(방안→설계→개발→검토→구현·테스트)를 따른다.
- U6(기동 노드) 게임 검증은 커리어에서 추적 기지/관제 센터가 업그레이드되어 노드가 열린 뒤, Claude가 직접 궤도에 올린 기체로 수행한다.

## 1단계 범위
| 묶음 | 내용 |
|---|---|
| A. 커리어 상태·계약 | 자금·과학·평판, 시설 레벨 조회. 계약 목록(제안/진행/완료), 계약별 목표 조건과 보상, 계약 수락 |
| B. 과학 실험 | 활성 기체의 실험 장치 목록(승무원 보고, 미스터리 구 등)과 현재 상황에서 얻을 수 있는 과학 값, 실험 실행, 보관 데이터 조회 |
| C. 발사·회수 | VAB/SPH에 저장된 기체(.craft) 목록, 선택한 기체를 발사대/활주로에 올려 발사 준비, 착륙·착수 후 기체 회수(보상 정산) |
| G. 비행체 조립 (회귀 추가) | 해금 부품 카탈로그(비용·질량·크기·엔진 성능·자원), Claude가 보낸 **설계도(스택 트리 + 방사형 대칭 부착)**로 모드가 부착 위치·스테이징을 계산해 `.craft`를 만들고 세이브의 `Ships/VAB`(또는 SPH)에 저장. 저장 전 검증(해금 여부, 시설 한계 부품 수·질량, 자금, 예상 Δv·TWR), 미리보기(dry run) 지원 |
| D. 상승 제어 | 목표 자세(pitch/heading/roll) 유지 조향, 조건 대기(`wait_until`: 고도·Ap·Ap 도달 시간·속도·연료 소진·상황 변화 등, 최대 대기 시간), 스테이지별 Δv·TWR·다음 스테이징 내용 |

## 채택 방안
기존 구조(Mod HTTP + App MCP)를 그대로 확장한다.
- Mod: 묶음별 핸들러 추가(`CareerHandler`, `ScienceHandler`, `LaunchHandler`, `AttitudeController`, `WaitHandler`, `StageInfo`). 조향은 Mod 안에서 매 물리 틱 동작하는 컨트롤러가 담당(Claude 호출 지연과 무관하게 자세 유지).
- App: 묶음별 MCP 도구 추가. `wait_until`은 긴 대기를 위해 요청별 타임아웃을 따로 둔다.
- 조립은 VAB 에디터 UI를 조작하지 않고, 설계도→`.craft` 생성으로 한다(사용자 결정, 2026-11-07 회귀). 사용자가 만든 기체나 스톡 기체도 그대로 발사할 수 있다.

## 비범위 (1단계)
- 기술 연구(과학 소비), 시설 업그레이드, 시간 가속, 과학 데이터 전송(안테나), EVA, 착륙 자동화, 자동 상승(launch_to_orbit) — 계약이 요구할 때 추가
- VAB 에디터 UI 조작, 표면 자유 부착(임의 위치), 날개·비행기 설계 최적화

## 위험·확인 필요
- 방사형 부착 위치(부모 반지름) 계산과 생성한 `.craft`가 VAB·발사에서 그대로 열리는지 — 게임 안에서 확인 필요
- 계약·과학·발사·회수 API 이름은 설계 단계에서 `Assembly-CSharp.dll` 리플렉션으로 확인
- 발사·회수는 게임 장면을 바꾼다(비행↔KSC). 장면 전환 중 요청 처리 규칙 필요
- 조향 컨트롤러의 안정성(진동·과조향)은 실제 로켓으로 튜닝 필요
- 커리어 초반 부품으로 궤도에 오를 수 있는 로켓은 사용자가 VAB에서 설계해야 함
