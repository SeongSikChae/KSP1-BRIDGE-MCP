## 핵심 코드 초안
### A1 Prediction (KSP API 확인: Vessel.perturbation/srf_velocity/atmDensity, ModuleEngines.maxFuelFlow/thrustPercentage/atmosphereCurve/finalThrust/EngineIgnited, CelestialBody.GetPressure/GetTemperature/GetDensity)
```csharp
var engines = active engines (EngineIgnited && isOperational && !flameout);
double m = v.totalMass;                        // t
double g0 = 9.80665;
Func<double,double> thrustAt = h => Σ e.maxFuelFlow*(e.thrustPercentage/100)*e.atmosphereCurve.Evaluate((float)body.GetPressureAtm(h))*g0; // kN
double flow = Σ e.maxFuelFlow*(e.thrustPercentage/100);   // t/s
double fuel = Σ propellant mass on vessel (engine propellant names, density>0);
// drag: perturbation = 비중력 가속도(추력+항력). 현재 추력 벡터 = nose * Σ finalThrust / m
Vector3d aDrag = v.perturbation - nose * (Σ e.finalThrust / m);
double dragAccel = Math.Max(0, -Vector3d.Dot(aDrag, v.srf_velocity.normalized));
double q = 0.5 * v.atmDensity * v.srfSpeed²;  // Pa (density kg/m³)
double cdaPerMass = q > 50 ? dragAccel / q : 0; // m²/t 단위 흡수 (a = q·k)
// 수직 1D 적분 (하강 중일 때만): 
//  stop: thrust on, until vz >= 0 → time, distance, dv(Σ a_thrust dt), fuel 소진 시 null
//  impact: thrust off, until altitude_terrain <= 0 → time
//  a = -g(h) + (thrust(h)/m)(stop만) + q(h,vz)·k  (항력은 속도 반대 = 하강 중 위쪽)
//  ρ(h) = body.GetDensity(body.GetPressure(h), body.GetTemperature(h)), 지형 높이 = altitude_asl - altitude_terrain 고정
```
### A3 TriggerManager
```csharp
class Trigger { int Id; string Name; Condition When; List<Dictionary<string,object>> Actions; bool Repeat; string State="armed"; double? FiredMet; object FiredValue; string Error; bool LastTrue; Guid VesselId; }
static void FixedUpdate() {
  v = FlightGlobals.ActiveVessel; if (v==null || scene!=FLIGHT) { Clear(); return; }
  foreach t in armed: if (t.VesselId != v.id) continue;
     bool now = Evaluate(t.When, v);            // WaitHandler와 같은 필드 읽기 공용화(FlightFields.Read)
     if (now && (!t.Repeat || !t.LastTrue)) Run(t, v);
     t.LastTrue = now;
}
Run: foreach action → throttle: FlightInputHandler.state.mainThrottle; stage: StageManager.ActivateNextStage();
     attitude: AttitudeController.Set(...); release_attitude: AttitudeController.Release(); sas: ActionGroups.SetGroup(SAS,on);
     action_group: ControlHandler 로직 재사용. 예외 → State=failed, Error=msg, break.
Hook: onVesselChange / onGameSceneLoadRequested → Clear()
```

- 등록 검증: field 존재, op(>=,<=,==), action type·값 범위 → 400
