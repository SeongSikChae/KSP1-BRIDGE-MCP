# 폭발진단 개발

단축(바로 구현)으로 방안·설계 없이 진행한다(2026-11-14 사용자 결정).

## 배경

TestB(SRB 2 + Swivel + Terrier) 80km 궤도 비행에서 `auto_stage`가 SRB를 떼어 냈다(stage 3→2). 분리 후 0.17~0.20초 만에 하단 `fuelTank.long`이 폭발했고, 그 아래 Swivel 단(Δv 약 1,700 m/s)도 함께 잃었다. revert 후 같은 계획으로 다시 띄워도 똑같이 재현됐다. 분리 순간 동압은 약 45 kPa였다.

```
01:23:57.321 [KspBridge] stage request confirmed: stage 3 -> 2
01:23:57.356 [KspBridge] staging sets: stage 2 parts 8 ...
01:23:57.528 fuelTank.long Exploded!! - blast awesomeness: 0.5
01:23:57.555 [KspBridge] staging sets: stage 2 parts 6 ... spent engines 0 kept engines 1
```

KSP.log에는 `Exploded!!`만 있고 원인이 없다. flight event에도 부품 소멸 기록이 없다. 그래서 충돌인지 구조 파손인지 가릴 수 없다.

## 조사 결과 (Assembly-CSharp 디컴파일)

| 원인 | GameEvents | 인자 | Fire 시점 |
| --- | --- | --- | --- |
| 다른 부품과 충돌 | `onCollision` | `EventReport`(origin=부딪힌 부품, other=상대 부품 제목, param=상대 속도 m/s) | `Part.HandleCollision`: `explode()` **뒤** |
| 지형·기타 물체 충돌 | `onCrash` | 같음(other=지형/물체 이름) | 같음. `Vessel.CheckKill`은 param 0 |
| 착수 충돌 | `onCrashSplashdown` | `EventReport` | `PartBuoyancy` |
| 과열 | `onOverheat` | `EventReport`(msg="현재 / 한계") | `_CheckPartTemp`: `explode()` 앞 |
| 과압·과G | `onOverPressure`, `onOverG` | `EventReport`(msg 동일) | `explode()` 앞 |
| 접합부 파손 | `onPartJointBreak` | `(PartJoint, float breakForce)` | `PartJoint.OnJointBreak`. `DestroyJoint`(디커플 등 정상 해체)는 0으로 Fire |
| 부품 소멸 | `onPartWillDie` → `onPartDie` | `Part` | `Part.Die()` |

- `Part.HandleCollision`은 상대 속도가 `crashTolerance` 이하이면 return한다. 넘으면 `explode()`(→ `onPartWillDie` → `onPartDie`)를 먼저 부르고, 그 **뒤에** `onCollision`/`onCrash`를 Fire한다. 그래서 충돌로 터진 경우 원인 이벤트가 소멸 이벤트보다 **늦게** 온다. 같은 프레임이다.
- 충돌 로그 줄(`collided into ... relative velocity`)은 `GameSettings.VERBOSE_DEBUG_LOG`가 켜져 있을 때만 KSP.log에 남는다. 그래서 이번에 원인이 비어 있었다.
- 접합부가 파손되면 explode 없이 분리만 된다(`decouple(breakForce)`).

## 결정 (사용자 합의)

1. **출력**: flight event(`get_flight_events`)와 KSP.log `[KspBridge]` 줄에 같은 내용을 남긴다.
2. **기록 원인**: 충돌, 접합부 파손, 과열(과압·과G 포함), 부품 소멸 전체.
3. **대상**: 비행 씬의 로드된 기체 부품 전부. 떨어져 나간 잔해(분리된 SRB 등)도 포함한다. 활성 기체 여부는 `active`로 표시한다.
   - 이유: 잔해와 본체가 부딪히면 원인 이벤트가 잔해 쪽 부품에서 Fire될 수 있다.
   - 비행 계획 실행 여부와 관계없이 기록한다. step은 계획이 실행 중(`Coordinator.Running`)이면 `Coordinator.StepIndex`, 아니면 -1이다. -1은 `logic_reloaded` 등이 이미 쓰는 '단계 없음' 값이다. `StepIndex`는 계획이 완료·중단된 뒤에도 마지막 단계 번호를 유지하므로 그대로 쓰지 않는다(구현 검토 R4-2-B-2 수용, 단위 3에서 변경).
   - 부품 소멸은 `onPartDie`가 아니라 `onPartWillDie`로 잡는다. `Part.Die()`는 `onPartWillDie` → 자식 분리·소멸 → `onPartDie` 순서다. `onPartDie` 때는 부품이 이미 기체에서 떨어진 뒤라 기체의 동압·G를 읽을 수 없다. 직전 상태를 남기려는 요구에 맞추려고 `onPartWillDie`를 쓴다(검토 지적 수용).
   - `Vessel.Die`(회수, 잔해 정리)는 부품을 `Part.Die()`가 아니라 `UnityEngine.Object.Destroy`로 없앤다(디컴파일 확인). 그래서 `onPartWillDie`가 오지 않고 `part_lost`도 남지 않는다. EVA 탑승도 `KerbalEVA.proceedAndBoard`가 `base.vessel.Die()`를 부르므로 같은 경로다(디컴파일 확인).
4. **새 이벤트 타입** (기존 타입·필드는 바꾸지 않는다)

| type | 원천 | data |
| --- | --- | --- |
| `part_lost` | `onPartWillDie` | `part`(부품 이름), `part_id`(persistentId), `vessel`, `vessel_id`, `active`, `q_kpa`(기체 동압), `g`(기체 geeForce), `temp`, `max_temp`, `skin_temp`, `skin_max_temp` |
| `part_collision` | `onCollision`·`onCrash`·`onCrashSplashdown` | `kind`(`part`·`crash`·`splashdown`), `part`, `part_id`, `vessel_id`, `active`, `other`, `speed`(EventReport.param, m/s), `crash_tolerance` |
| `part_limit` | `onOverheat`·`onOverPressure`·`onOverG` | `kind`(`overheat`·`pressure`·`g`), `part`, `part_id`, `vessel_id`, `active`, `msg` |
| `part_joint_break` | `onPartJointBreak`, `breakForce > 0`만 | `part`(child), `part_id`, `parent`, `parent_id`, `vessel_id`, `active`, `force`(kN) |

   - `part_joint_break`의 `breakForce == 0`은 정상 해체(디커플·도킹 해제)라서 남기지 않는다.
   - 충돌 원인 이벤트는 `part_lost` 뒤에 온다. 도구 설명에 적어 둔다.
5. **값**: 실수는 소수 3자리로 반올림한다. 값을 읽을 수 없으면(origin이나 vessel이 null) null로 둔다. 핸들러 예외는 잡아서 `[KspBridge]` LogError 한 줄만 남기고, KSP 이벤트 처리에 전파하지 않는다.
6. **버전**: Logic `Routes.Version` 0.2.33 → 0.2.34(단위 1), 0.2.35(단위 3). 로더·`ILogic`은 바뀌지 않으므로 `reload_mod`로 배포한다. 도구 설명(App.Tools)은 Tools 빌드 후 `reload_app`으로 반영한다.
7. **버퍼 분리** (구현 검토 R4-2-B-1 수용, 2026-11-14 사용자 결정): 부품 이벤트가 계획 이벤트와 같은 500칸 링을 쓰면 큰 기체가 부서질 때 계획 이벤트(`staged`, `step_*` 등)가 밀려난다. 그래서 부품 이벤트는 별도 500칸 링에 둔다.
   - seq는 하나로 이어 매긴다. `Since`는 두 링을 seq 순으로 합쳐 돌려준다. 응답 형식(`events`, `next`, `truncated`, `epoch`)은 바뀌지 않는다.
   - `truncated`는 덮어써 잃은 이벤트 중 가장 큰 seq(`DroppedSeq`)로 판정한다: `since < DroppedSeq`. 링이 하나일 때의 `since < At(0).Seq - 1`과 같은 뜻이다.
   - 핸드오버에 `dropped_seq`를 더한다. 없으면(이전 Logic) 복원한 이벤트 중 가장 작은 seq − 1로 둔다. 기존 판정과 같다. 복원할 때는 type이 부품 이벤트 4종이면 부품 링, 아니면 계획 링에 넣는다.
   - 부품 이벤트는 trial(Submit·ReplaceSteps의 첫 명령 계산)을 거치지 않고 바로 저장한다. 계획 이벤트와 달리 다음 Tick에서 다시 생기지 않기 때문이다(R4-2-B-3도 함께 해소).

```csharp
// PartLossLog.cs
namespace KspBridge.Flight
{
    /// <summary>Part loss and its causes on loaded vessels (debris included) as flight events and [KspBridge] log lines.
    /// A collision's cause fires after part_lost: Part.HandleCollision calls explode() before onCollision/onCrash (decompile checked).
    /// Instance handlers: EvtDelegate reads evt.Target.GetType() (see FlightScene).</summary>
    public sealed class PartLossLog
    {
        private static PartLossLog _hooked;

        public static void Hook()
        {
            Unhook();
            PartLossLog s = new PartLossLog();
            GameEvents.onPartWillDie.Add(s.OnWillDie);
            GameEvents.onCollision.Add(s.OnCollision);
            GameEvents.onCrash.Add(s.OnCrash);
            GameEvents.onCrashSplashdown.Add(s.OnSplashdown);
            GameEvents.onOverheat.Add(s.OnOverheat);
            GameEvents.onOverPressure.Add(s.OnOverPressure);
            GameEvents.onOverG.Add(s.OnOverG);
            GameEvents.onPartJointBreak.Add(s.OnJointBreak);
            _hooked = s;
        }

        public static void Unhook()
        {
            PartLossLog s = _hooked;
            if (s == null)
            {
                return;
            }
            _hooked = null;
            GameEvents.onPartWillDie.Remove(s.OnWillDie);
            GameEvents.onCollision.Remove(s.OnCollision);
            GameEvents.onCrash.Remove(s.OnCrash);
            GameEvents.onCrashSplashdown.Remove(s.OnSplashdown);
            GameEvents.onOverheat.Remove(s.OnOverheat);
            GameEvents.onOverPressure.Remove(s.OnOverPressure);
            GameEvents.onOverG.Remove(s.OnOverG);
            GameEvents.onPartJointBreak.Remove(s.OnJointBreak);
        }

        private void OnWillDie(Part p) => Safe("part_lost", () =>
        {
            Vessel v = p?.vessel;
            Emit("part_lost", Base(p, new Dictionary<string, object>
            {
                ["vessel"] = v?.vesselName,
                ["q_kpa"] = R(v?.dynamicPressurekPa),
                ["g"] = R(v?.geeForce),
                ["temp"] = R(p?.temperature),
                ["max_temp"] = R(p?.maxTemp),
                ["skin_temp"] = R(p?.skinTemperature),
                ["skin_max_temp"] = R(p?.skinMaxTemp),
            }));
        });

        private void OnCollision(EventReport r) => Collision("part", r);
        private void OnCrash(EventReport r) => Collision("crash", r);
        private void OnSplashdown(EventReport r) => Collision("splashdown", r);

        private void OnOverheat(EventReport r) => Limit("overheat", r);
        private void OnOverPressure(EventReport r) => Limit("pressure", r);
        private void OnOverG(EventReport r) => Limit("g", r);

        /// <summary>msg holds "current / limit" (EventReport.msg); param is explosionPotential, not a measurement.</summary>
        private static void Limit(string kind, EventReport r) => Safe("part_limit", () =>
            Emit("part_limit", Base(r?.origin, new Dictionary<string, object>
            {
                ["kind"] = kind,
                ["msg"] = r?.msg,
            })));

        private static void Collision(string kind, EventReport r) => Safe("part_collision", () =>
            Emit("part_collision", Base(r?.origin, new Dictionary<string, object>
            {
                ["kind"] = kind,
                ["other"] = r?.other,
                ["speed"] = R(r?.param),
                ["crash_tolerance"] = R(r?.origin?.crashTolerance),
            })));

        private void OnJointBreak(PartJoint j, float force)
        {
            if (force <= 0)
            {
                return;   // DestroyJoint (decouple, undock) fires 0
            }
            Safe("part_joint_break", () =>
            {
                Part parent = j?.Parent;
                Emit("part_joint_break", Base(j?.Child, new Dictionary<string, object>
                {
                    ["parent"] = parent?.partInfo?.name,
                    ["parent_id"] = parent != null ? (object)(double)parent.persistentId : null,
                    ["force"] = R(force),
                }));
            });
        }

        /// <summary>part, part_id, vessel_id, active, then the extra fields (null when p or its vessel is null).</summary>
        private static Dictionary<string, object> Base(Part p, Dictionary<string, object> extra)
        {
            Vessel v = p?.vessel;
            Dictionary<string, object> d = new Dictionary<string, object>
            {
                ["part"] = p?.partInfo?.name,
                ["part_id"] = p != null ? (object)(double)p.persistentId : null,
                ["vessel_id"] = v != null ? (object)(double)v.persistentId : null,
                ["active"] = v != null && v == FlightGlobals.ActiveVessel,
            };
            foreach (KeyValuePair<string, object> kv in extra)
            {
                d[kv.Key] = kv.Value;
            }
            return d;
        }

        private static object R(double? x) => x.HasValue ? (object)Math.Round(x.Value, 3) : null;

        private static void Emit(string type, Dictionary<string, object> data)
        {
            FlightEvents.Add(type, Coordinator.StepIndex, data);
            UnityEngine.Debug.Log("[KspBridge] " + type + " " + Format(data));
        }

        /// <summary>k=v pairs in insertion order; null as "null".</summary>
        private static string Format(Dictionary<string, object> d) =>
            string.Join(" ", d.Select(kv => kv.Key + "=" + (kv.Value ?? "null")).ToArray());

        /// <summary>A handler never throws into KSP's event loop.</summary>
        private static void Safe(string what, Action a)
        {
            try
            {
                a();
            }
            catch (Exception e)
            {
                UnityEngine.Debug.LogError("[KspBridge] " + what + " record failed: " + e);
            }
        }
    }
}

// BridgeLogic.StartCore: hook inside the same try, undo on failure
FlightScene.Hook();
FlightReset.Hook();
PartLossLog.Hook();
Debugging.DebugState.Hook();
// catch: UnhookAfterFailedStart("part loss", PartLossLog.Unhook);   // after the flight reset line

// BridgeLogic.Stop: right after FlightReset.Unhook, before Coordinator.Stop
// (no part event may reach the buffer after Coordinator.Stop serialized and cleared it)
try
{
    PartLossLog.Unhook();
}
catch (Exception e)
{
    UnityEngine.Debug.LogError("[KspBridge] part loss unhook failed: " + e);
}
IList<string> released = Coordinator.Stop(_context);

// Routes.cs
public const string Version = "0.2.34";
```

```csharp
// FlightEvents.cs
/// <summary>One ring of events; overwriting the oldest raises DroppedSeq.</summary>
private sealed class Ring
{
    private readonly FlightEvent[] _buf = new FlightEvent[Capacity];
    private int _start;
    public int Count;

    public FlightEvent At(int i) => _buf[(_start + i) % Capacity];

    public void Put(FlightEvent e)
    {
        if (Count < Capacity)
        {
            _buf[(_start + Count) % Capacity] = e;
            Count++;
            return;
        }
        DroppedSeq = Math.Max(DroppedSeq, _buf[_start].Seq);
        _buf[_start] = e;
        _start = (_start + 1) % Capacity;
    }

    public void Clear() { Array.Clear(_buf, 0, Capacity); _start = 0; Count = 0; }
}

private static readonly Ring _plan = new Ring();   // every event except the part diagnostics
private static readonly Ring _parts = new Ring();  // part_lost, part_collision, part_limit, part_joint_break

/// <summary>Largest seq lost by overwriting (either ring) or before the restored window; since &lt; DroppedSeq means truncated.</summary>
public static long DroppedSeq { get; private set; }

private static readonly HashSet<string> PartTypes = new HashSet<string> { "part_lost", "part_collision", "part_limit", "part_joint_break" };

/// <summary>Part diagnostics: own ring, never part of a trial (they do not recur on the next Tick).</summary>
public static void AddPart(string type, int step, Dictionary<string, object> data)
{
    FlightEvent e = Create(type, step, data);   // the Ut/Met/Type/Step/Data body of Add
    e.Seq = ++LastSeq;
    _parts.Put(e);
}

// Push: e.Seq = ++LastSeq; _plan.Put(e);

/// <summary>Both rings oldest first, merged by seq (two cursors).</summary>
private static IEnumerable<FlightEvent> Merged()
{
    int i = 0, j = 0;
    while (i < _plan.Count || j < _parts.Count)
    {
        if (j >= _parts.Count || (i < _plan.Count && _plan.At(i).Seq < _parts.At(j).Seq))
        {
            yield return _plan.At(i++);
        }
        else
        {
            yield return _parts.At(j++);
        }
    }
}

// Save(): Merged() in the existing dictionary form (unchanged).
// Since(): the same loop over Merged(); truncated = since < DroppedSeq.
// Clear(): both rings, DroppedSeq = 0, trial, LastSeq.
```
