# 기체설계 방안

이슈: [#1 VAB/SPH 기체 설계 및 검증 도구](https://github.com/SeongSikChae/KSP1-BRIDGE-MCP/issues/1)

## 문제

KspBridge는 런타임 리로드 골격(`get_status`, `reload_mod`, `reload_app`)만 있다.
MCP 클라이언트(AI)가 VAB/SPH에서 기체를 만들고, 그 기체가 구조적으로 맞는지·날 수 있는지·모양이 의도대로인지 확인할 수단이 없다.

## 목표

- AI가 VAB/SPH 에디터에서 부품을 하나씩 붙이고 고치며 기체를 설계한다.
- 설계 중 언제든 구조·성능·모양을 검증한다.
- 결과를 게임 기본 방식으로 저장하고, 기존 기체를 불러와 고치고, 발사대로 보낼 수 있다.
- 사용자는 같은 과정을 게임 화면에서 그대로 본다.

## 대안과 채택

### 1. 입력 모델

| 대안 | 장점 | 단점 |
| --- | --- | --- |
| **에디터 세션 증분 조작 (채택)** | 실제 에디터 기체를 작은 조작으로 고침. 단계마다 검증·렌더 가능, 사용자가 화면에서 봄, 실패 지점이 작음 | 에디터 상태(선택·Undo)와 동기화 필요, 호출 수가 많음 |
| 선언형 전체 제출 | 상태 없음, 재현 쉬움 | 수정마다 전체 재조립, 오류 위치를 찾기 어려움, 화면과 분리 |
| 혼합 | 두 방식 장점 | 두 경로 유지 비용 |

채택 이유: 게임 에디터가 이미 부착·대칭·스테이징을 처리하므로, 그 위에 작은 조작을 얹는 편이 조립 결과가 게임과 어긋나지 않는다.

### 2. 실행 씬

| 대안 | 장점 | 단점 |
| --- | --- | --- |
| **VAB/SPH 에디터 씬만 (채택)** | 게임의 부착 규칙·대칭·스테이징·엔지니어 리포트를 그대로 사용 | 에디터 씬이 필요. 필요하면 도구가 에디터로 전환 |
| 어느 씬에서나 오프스크린 | 씬 제약 없음 | 에디터와 다른 조립 결과가 나올 위험을 직접 관리해야 함 |

### 3. 부품 배치

| 대안 | 장점 | 단점 |
| --- | --- | --- |
| **노드+표면 부착, 보정 허용 (채택)** | 스택은 부모/자식 노드 이름, 표면 부착은 부모 기준 방위각·높이. 에디터 offset/rotate와 같은 보정을 별도 조작으로 허용해 날개 각도 등 표현 가능 | 보정 조작이 추가됨 |
| 노드+표면 부착만 | 단순 | 날개 각도·위치 미세 조정 불가 |
| 좌표 직접 지정 | 자유도 높음 | 부착 관계 추론이 어렵고 게임 규칙과 어긋나기 쉬움 |

### 4. 검증 범위

세 가지를 모두 제공한다.

- **구조**: 부품 존재·해금, 부착 노드 유효성, 겹침·고아 부품, 저장 가능 여부
- **성능 수치**: 스테이지별 질량·추력·TWR·Δv, CoM/CoT/CoL, 안정성 경고
- **렌더 이미지**: 모양 확인

### 5. 렌더 반환

| 대안 | 장점 | 단점 |
| --- | --- | --- |
| **MCP 이미지 콘텐츠 (채택)** | 전용 카메라로 오프스크린 촬영한 PNG를 도구 결과에 담아 AI가 바로 봄. 여러 뷰 | 응답 크기 증가 |
| 파일 저장 + 경로 | 응답 작음 | AI가 이미지를 따로 읽어야 함 |

## 채택 방안

VAB/SPH 에디터 씬에서 현재 에디터 기체를 대상으로, 부품 추가·부착·제거·이동/회전 보정·대칭 같은 작은 조작 도구를 제공한다.
배치는 노드 이름(스택)과 부모 기준 방위각·높이(표면 부착)로 지정하고, 필요하면 보정 조작으로 다듬는다.
검증은 구조·성능 수치를 텍스트로, 모양을 전용 카메라 PNG(MCP 이미지 콘텐츠)로 돌려준다.
저장·불러오기·발사대 보내기는 게임 에디터 기능을 그대로 쓴다.

## 범위

- 에디터 진입(VAB/SPH), 새 기체 시작
- 부품 조회, 부품 추가·부착·제거, offset/rotate 보정, 대칭
- 구조 검증, 성능 수치, 렌더 이미지
- 기존 `.craft` 불러오기, 저장
- 스테이징 조회·편집
- 부품 설정 편집(추력 제한, 자원 양 등)
- 발사대(활주로) 보내기

## 비범위

- 비행 제어·발사 후 조작
- 커리어·계약·연구
- 중계 방송
- 기체 자동 설계(최적화)
