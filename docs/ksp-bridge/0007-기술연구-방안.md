# KspBridge 기술 연구 — 방안

선행: `0004`~`0006` 커리어 1단계 (남은 검증: sas 저속, decline, click_dialog_button)

## 문제·목표
- 다음 계약 "대기권을 탈출해 보세요!"(70km)·"커빈 궤도 형성하기!"는 시작 부품(플리 부스터)으로 불가능하다.
- 과학 28.5로 기술 트리 노드를 연구해 액체 엔진·연료 탱크·디커플러 등을 해금해야 한다.
- Claude가 R&D 화면 없이 기술 트리를 조회하고 노드를 연구할 수 있어야 한다.

## 조사 결과 (KSP 1.12.5 디컴파일)
- 트리 구조: `AssetBase.RnDTechTree.GetTreeNodes()` → `ProtoRDNode`(parents, AnyParentToUnlock, tech.techID/scienceCost)
- 제목: `ResearchAndDevelopment.GetTechnologyTitle(techID)`, 상태: `ResearchAndDevelopment.GetTechnologyState(techID)`
- R&D 화면의 `RDTech.ResearchTech()` 동작: 과학 부족·R&D 시설 비용 한도(`GameVariables.GetScienceCostLimit`) 확인 → `AddScience(-cost, RnDTechResearch)` → 해금(Bypass면 부품 자동 구매)
- 화면 밖 해금: `ResearchAndDevelopment.Instance.UnlockProtoTechNode(node)` (Bypass면 부품 자동 구매) — 스톡 치트 `CheatTechnology`도 이 함수 + `RefreshTechTreeUI` + `ContractDefs.Instance.TechResearched`를 쓴다
- 현재 세이브: `BypassEntryPurchaseAfterResearch = True` → 부품 구매 기능 불필요

## 채택 방안
- R&D 화면 로직을 그대로 따라 검사(선행 노드, 과학, 비용 한도) 후 과학 차감 + `UnlockProtoTechNode` + UI·계약 갱신
- 조회는 기본으로 "연구됨 + 지금 연구 가능" 노드만 부품 목록과 함께, 전체 트리는 요청 시 부품 없이 반환(도구 결과 크기 제한)

## 비범위
부품 개별 구매(Bypass 꺼진 세이브), 시설 업그레이드, 기술 트리 모드 대응
