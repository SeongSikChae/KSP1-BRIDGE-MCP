# 추적소이동 개발

이슈: [#23 장면 도구: Tracking Station으로 이동](https://github.com/SeongSikChae/KSP1-BRIDGE-MCP/issues/23)
방안: [0037-추적소이동-방안.md](0037-추적소이동-방안.md) · 설계: [0038-추적소이동-설계.md](0038-추적소이동-설계.md)

## 공통

- 실측은 MCP 응답으로만 확인한다. 장면을 바꾸기 전에 `get_status`로 현재 장면과 실행 중인 계획을 확인한다.
- Logic DLL을 빌드한 뒤 `reload_mod`로 교체한다. 커밋하는 단위마다 `Routes.cs`의 Logic 버전을 patch 단위로 올린다(현재 0.2.40).
- 순서: 1 → 2. 단위마다 구현 → 검증 → 커밋 여부를 확인한다.

## 단위 1. Logic: Tracking Station 이동

**대상**
- `src/KspBridge.Logic/Flight/FlightReset.cs`: `OpenTrackingStation()`, `TrackingStationUnavailable`, `LoadTrackingStation`
- `src/KspBridge.Logic/Flight/VesselSwitch.cs`: `RequireNotPending()` (기존 `Switch`의 같은 검사도 이 메서드를 부른다)
- `src/KspBridge.Logic/Handlers/FlightHandler.cs`: `POST /api/scene/tracking_station`
- `src/KspBridge.Logic/Routes.cs`: 버전

**코드 초안**

```csharp
// FlightReset.cs
/// <summary>open_tracking_station (design 0038): the Space Center building (CanGoInTrackingStation, save, load) or, in flight,
/// the pause menu's Tracking Station button (both game settings and ClearToSave, then onSceneConfirmExit, save Game.Updated(),
/// load). Every check runs before anything changes.</summary>
public static object OpenTrackingStation()
{
    RequireNoPendingRecovery();
    VesselSwitch.RequireNotPending();
    RequireSceneReady();
    RequireStockGame("open_tracking_station");
    GameParameters p = HighLogic.CurrentGame.Parameters;
    GameScenes scene = HighLogic.LoadedScene;
    if (scene == GameScenes.TRACKSTATION)
    {
        return new Dictionary<string, object> { ["accepted"] = true, ["already_open"] = true };
    }
    if (scene == GameScenes.SPACECENTER)
    {
        if (!p.SpaceCenter.CanGoInTrackingStation)
        {
            throw TrackingStationUnavailable("going into the tracking station is disabled in this game");
        }
        LoadTrackingStation(Save, "");
        return new Dictionary<string, object> { ["accepted"] = true, ["from"] = "SPACECENTER" };
    }
    if (scene != GameScenes.FLIGHT)
    {
        throw ApiException.SceneNotAllowed("open_tracking_station");
    }
    Vessel v = Guard.ActiveVessel();
    if (!p.Flight.CanLeaveToTrackingStation || !p.SpaceCenter.CanGoInTrackingStation)
    {
        throw TrackingStationUnavailable("leaving to the tracking station is disabled in this game");
    }
    ClearToSaveStatus c = FlightGlobals.ClearToSave(false);   // no game log
    if (c != ClearToSaveStatus.CLEAR)
    {
        throw TrackingStationUnavailable("cannot leave " + v.vesselName + " now: " + c);
    }
    bool aborted = Coordinator.Running;
    if (aborted)
    {
        Coordinator.Abort("tracking_station", null, null);
    }
    Control.ManualControl.StopPulse("tracking_station");
    LoadTrackingStation(() =>
    {
        GameEvents.onSceneConfirmExit.Fire(HighLogic.CurrentGame.startScene);
        GamePersistence.SaveGame(HighLogic.CurrentGame.Updated(), "persistent", HighLogic.SaveFolder, SaveMode.OVERWRITE);
    }, aborted ? " (the flight plan was already aborted)" : "");
    return new Dictionary<string, object> { ["accepted"] = true, ["from"] = "FLIGHT" };
}

/// <summary>Saves and requests TRACKSTATION; 500 tracking_station_failed when that throws or no load request follows
/// (LoadScene fires onGameSceneLoadRequested at once, which sets _requestedScene and _sceneLoading).</summary>
private static void LoadTrackingStation(Action save, string stopped)
{
    try
    {
        save();
        HighLogic.LoadScene(GameScenes.TRACKSTATION);
    }
    catch (Exception e)
    {
        throw new ApiException(500, "tracking_station_failed", e.GetType().Name + ": " + e.Message + stopped);
    }
    if (_requestedScene != GameScenes.TRACKSTATION || !_sceneLoading)
    {
        throw new ApiException(500, "tracking_station_failed", "the game did not start loading the tracking station" + stopped);
    }
}

private static ApiException TrackingStationUnavailable(string why) => new ApiException(409, "tracking_station_unavailable", why);
```

```csharp
// VesselSwitch.cs
internal static void RequireNotPending()
{
    if (_targetId != null)
    {
        throw new ApiException(409, "switch_pending", "a vessel switch is in progress (get_status reset.switch)");
    }
}

// FlightHandler.cs
yield return new Route("POST", "/api/scene/tracking_station", (m, b, q) => FlightReset.OpenTrackingStation());
```

- `ManualControl.StopPulse`가 펄스가 없을 때 아무것도 하지 않으므로, 메시지에는 계획 중단 여부만 적는다(펄스는 `get_status.translate`로 확인).

**검증**
- Logic 빌드 성공, `reload_mod`
- 실측(HTTP 직접 호출: `POST http://127.0.0.1:8085/api/scene/tracking_station` 본문 `{}`)
  - EDITOR → 409 `scene_not_allowed`
  - SPACECENTER → 200 `from SPACECENTER` → `get_status` `scene TRACKSTATION`, `reset.requested_scene TRACKSTATION`, `reset.scene_ready true`
  - TRACKSTATION에서 다시 호출 → 200 `already_open`
  - FLIGHT(궤도 기체, 정지) + 가속 없는 계획 실행 중(`attitude` 단계, `throttle 0`, 긴 `until`) → 200 `from FLIGHT` → `get_flight_events`에 `plan_aborted reason tracking_station` → TRACKSTATION 로드 완료. 엔진을 켠 계획은 `ClearToSave`가 막으므로 쓰지 않는다.
  - FLIGHT 대기권 비행 중 + 계획 실행 중(발사대에서 상승 계획, 고도 수백 m) → 409 `tracking_station_unavailable`(`NOT_IN_ATMOSPHERE` 등), 장면 그대로, `get_status.flight.plan_state`가 `running`으로 남고 `get_flight_events`에 `plan_aborted`가 없다(방안 결정 3: 거부하면 계획은 계속)
- 설계 확인 항목: `scene_ready`가 TRACKSTATION에서 true가 되는지, 접수가 500 없이 되는지(동기 로드 요청)

**선행 단위**: 없음

[McpServerTool(Name = "open_tracking_station", Destructive = true)]
[Description("Go to the Tracking Station: from the space center like its building, or from flight like the pause menu's Tracking Station button " +
    "(saves; a running flight plan is aborted, reason tracking_station). Returns {accepted, from} at once: poll get_status until " +
    "reset.requested_scene is TRACKSTATION and reset.scene_ready. {accepted, already_open} when already there: nothing loads, check " +

    "switch_pending, scene_loading, no_game, not_supported (mission games), scene_not_allowed (editor and other scenes), no_active_vessel. " +
    "tracking_station_failed (500) when saving or loading failed after the checks; its message says if the flight plan was already aborted.")]

    => client.SendAsync(HttpMethod.Post, "api/scene/tracking_station", new { }, ct);
