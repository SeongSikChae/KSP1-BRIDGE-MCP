# KspBridge 시설 업그레이드 — 방안

## 문제·목표
- 시설이 모두 레벨 0(최저)이라 다음 단계가 막힌다.
  - 기동 노드(U6 검증, 궤도 계약): 관제소(Mission Control) 레벨 필요 — 궤도에서 `add_maneuver_node`가 "upgrade the Tracking Station / Mission Control"로 거부됨
  - 부품 30개·발사대 18t 한도, R&D 연구 비용 한도 100, 동시 계약 수
- 자금 401,530이 있어 업그레이드 가능. Claude가 KSC 화면 클릭 없이 시설 정보·효과·비용을 보고 업그레이드할 수 있어야 한다.

## 조사 결과 (KSP 1.12.5 디컴파일)
- 업그레이드 버튼 → `SpaceCenterBuilding.UpgradeFacility`:
  1. 최대 레벨이면 중단
  2. `CurrencyModifierQuery.RunQuery(StructureConstruction, -cost, 0, 0).CanAfford()` 실패 시 중단
  3. `Funding.AddFunds(-cost, StructureConstruction)` → `Facility.SetLevel(level + 1)`
  - 사전에 `WarnOfObstructingVessels`: 시설 부지 위 기체가 있으면 경고 후 중단
- 비용: `UpgradeableFacility.GetUpgradeCost()`(난이도 배율 반영). 시설 객체는 KSC 장면에서만 존재
- 효과 수치: `GameVariables`(부품 수·질량·크기 한도, 연구 비용 한도, 동시 계약 수, 비행 계획(기동 노드) 해금, 궤도 예측 패치 수, 승무원 수, EVA, 전략 수)

## 채택 방안
- 로직 DLL에 핸들러 추가(로더 변경 없음 → `reload_mod`로 배포, KSP 재시작 불필요)
- 조회: 시설별 레벨·최대·업그레이드 비용·지불 가능 여부·현재/다음 레벨 효과
- 업그레이드: KSC 장면에서만, 스톡 버튼과 같은 검사 후 자금 차감·레벨 설정

## 비범위
시설 수리·다운그레이드·철거, 비행 중 업그레이드(스톡도 KSC에서만)
