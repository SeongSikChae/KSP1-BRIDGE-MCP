# KspBridge 기술 연구 — 설계

선행: `0007-기술연구-방안.md`

## HTTP (Mod)
### GET /api/tech?all=true|false
- 커리어 아니면 409 `not_career`
- 응답
```json
{
  "science": 28.5,
  "cost_limit": 100,
  "nodes": [
    {"id": "basicRocketry", "title": "기초 로켓공학", "cost": 5,
     "state": "researched | researchable | locked",
     "parents": ["start"], "any_parent": false,
     "parts": [{"name": "liquidEngine3.v2", "title": "LV-909 ..."}]}
  ]
}
```
- `researchable`: 미연구 + 선행 조건 충족(any_parent면 하나, 아니면 전부). 과학 부족 여부는 별도 판단(cost와 science 비교)
- 기본(all=false): researched + researchable 노드만, parts 포함. all=true: 전체 노드, parts 생략(이름 수만 `part_count`)

### POST /api/tech/{id}/research
- 순서대로 검사: 커리어(409 `not_career`) → 노드 존재(404) → 이미 연구(409 `already_researched`) → 선행 노드(409 `prerequisites_missing`, 메시지에 부족한 노드) → 비용 한도(409 `cost_limit`) → 과학 부족(409 `not_enough_science`)
- 실행: `AddScience(-cost, RnDTechResearch)` → `UnlockProtoTechNode` → `RefreshTechTreeUI()` → `ContractDefs.Instance?.TechResearched(default)`
- 응답: `{"researched": id, "title", "cost", "science": 남은 과학, "parts_unlocked": [{name,title}]}`

## MCP 도구 (TechTools)
