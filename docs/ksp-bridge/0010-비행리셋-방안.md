# 비행리셋 방안

이슈: [#8 비행 리셋·회수 도구: revert_flight, recover_vessel, 발사대 비우기](https://github.com/SeongSikChae/KSP1-BRIDGE-MCP/issues/8)

관련: [0004-비행제어-방안.md](0004-비행제어-방안.md) (추후 대상: 기체 회수, 비행 리셋)

## 문제

- 비행을 다시 시도하려면 사용자가 화면에서 Revert 메뉴를 누르거나, 조립동을 다시 열고 `launch_craft`를 호출해야 한다. MCP 도구만으로는 "발사 → 실패 → 되돌리기 → 재시도"를 반복할 수 없다.
- 발사대·활주로에 기체가 남아 있으면 `launch_craft`가 게임의 발사 전 검사 대화상자(발사 지점 비우기)에서 멈춘다. 이 대화상자는 화면에서만 답할 수 있다.
- 다 쓴 기체를 치울 수단(Recover Vessel)도 없다.

## 목표

- MCP 도구만으로 비행을 되돌리고(발사 직후 / 조립동), 기체를 회수하고, 발사 지점을 비운 채 발사할 수 있다.
- 화면 입력이 필요한 대화상자에서 멈추지 않는다.
- 실행 중인 비행 계획이 남은 상태로 씬이 바뀌지 않는다.

## 대안과 채택

### 1. 도구 형태

| 대안 | 내용 | 단점 |
|---|---|---|
| **도구 셋 (채택)** | `revert_flight(target: launch\|editor)`, `recover_vessel`, `launch_craft`의 `clear_site` 옵션 | 도구 수가 늘어남 |
| 도구 하나 | `reset_flight(action: ...)` 하나로 묶음 | 인자 조합마다 유효 씬이 달라 설명이 복잡함 |

### 2. 실행 중인 비행 계획

| 대안 | 내용 | 단점 |
|---|---|---|
| **먼저 중단 (채택)** | revert·recover 전에 계획을 중단한다(`abort_flight`와 같은 해제: 스로틀 0, SAS 복원, 제어 해제). 이벤트 `plan_aborted`의 reason은 `revert`·`recover`·`leave` | 없음 |
| 거부 | 계획이 실행 중이면 409로 거부하고 `abort_flight`를 먼저 부르게 함 | 호출이 한 번 늘어남, 리셋 목적과 맞지 않음 |

### 3. 되돌릴 수 없는 상태

게임은 발사 뒤 상태(`FlightDriver`의 post-init·pre-launch 백업)가 있을 때만 Revert를 허용하고, 게임 설정(난이도의 Revert 허용)도 따른다. 이 조건이 아니면 409 `revert_unavailable`로 알리고 이유(백업 없음 / 게임 설정)를 붙인다. 게임 설정을 바꾸거나 우회하지 않는다.

### 4. 씬 전환 결과

`launch_craft`와 같이 요청을 받으면 바로 `{accepted}`를 돌려주고, 결과는 `get_status`(scene, 활성 기체)로 확인한다. 씬 전환을 기다리는 대기 도구는 만들지 않는다(0004 비범위와 같음).

### 5. 회수 대상과 대화상자

| 대안 | 내용 | 단점 |
|---|---|---|
| **활성 기체 + 발사 지점 기체, 대화상자 없음 (채택)** | 비행 씬: 활성 기체를 회수(게임의 회수 가능 조건을 따름: 착지·착수 상태). 비행 씬 밖(우주센터·조립동): `site`에 착지한 기체를 회수. 회수 결과(자금·과학·승무원)는 응답에 담고(비행 씬 회수는 씬이 바뀐 뒤 끝나므로 `get_status`에 담는다), 게임의 회수 결과 대화상자는 띄우지 않는다 | 게임 화면에서 회수 결과 창을 볼 수 없음 |
| 게임 회수 버튼과 같게 | 게임의 회수 요청 이벤트를 그대로 발생시킴 | 회수 결과 대화상자가 우주센터에서 열려 화면 입력을 기다림 |
| 임의 기체 지정 | id로 궤도의 기체도 회수 | 게임이 허용하지 않는 회수(궤도)와 섞임. 필요하면 이후에 다룸 |

### 6. 발사 지점 비우기

`launch_craft`에 `clear_site`(기본 false)를 둔다. true면 발사 전에 그 발사 지점에 착지한 기체를 5번과 같은 방식으로 회수한 뒤 발사한다. false면 지금과 같다(게임의 발사 전 검사가 대화상자를 띄움). 회수한 기체 목록을 응답에 담는다.

## 1차 범위

- `revert_flight(target: launch|editor)`: 비행 씬에서 발사 직후 상태 또는 조립동(VAB/SPH는 게임이 기억한 시설)으로 되돌림
- `recover_vessel`: 비행 씬의 활성 기체, 또는 `site`에 착지한 기체 회수
- `launch_craft(clear_site)`: 발사 지점을 비우고 발사
- `leave_flight`: 게임의 Space Center 버튼과 같이 기체를 남기고 우주센터로 나감(발사 지점 회수 실측 준비, 설계 단계에서 합의로 추가)
- `get_status`에 되돌릴 수 있는지(`can_revert_launch`, `can_revert_editor`), 회수할 수 있는지(`can_recover`), 씬 전환이 끝났는지(`scene_ready`) 표시

## 비범위

- quicksave·quickload, 저장 파일 관리
- 궤도에 있는 기체 회수, 여러 기체 일괄 회수
- 게임 설정(Revert 허용 여부) 변경
- 씬 전환 완료를 기다리는 대기 도구
