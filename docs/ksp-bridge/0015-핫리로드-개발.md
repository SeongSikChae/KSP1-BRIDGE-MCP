## 핵심 코드 초안
```csharp
// 로더
public static class LogicHost
{
    static ILogic _logic; public static int LoadCount; public static string LastError;
    static string Path => KSPUtil.ApplicationRootPath + "GameData/KspBridge/PluginData/KspBridge.Logic.dll";
    public static ILogic Create()
    {
        Assembly asm = Assembly.Load(File.ReadAllBytes(Path));
        Type t = asm.GetTypes().Single(x => typeof(ILogic).IsAssignableFrom(x) && !x.IsAbstract);
        return (ILogic)Activator.CreateInstance(t);
    }
    public static object Reload(LogicContext ctx, HttpServer server)   // 메인 스레드
    {
        ILogic next = Create();                         // 실패 → 예외, 기존 유지
        IList<string> released = _logic?.Stop() ?? new List<string>();
        try { server.SetRoutes(Base(ctx).Concat(next.Start(ctx))); }
        catch { _logic?.Start(ctx) ...; throw; }       // 복구
        _logic = next; LoadCount++; ...
    }
}
// KspBridgeAddon.FixedUpdate → LogicHost.FixedUpdate() → _logic?.FixedUpdate() (예외 로그)
```
- `/api/reload`는 디스패처(메인 스레드)에서 실행. HttpServer는 경로 배열을 참조 하나로 교체(요청 처리 중인 스레드는 이전 배열 사용)
- Mono 동일 이름 반복 로드 확인: H6 ②에서 확인. 실패하면 로직 csproj에서 빌드마다 `AssemblyName`에 타임스탬프 부여 + 로더는 `PluginData/KspBridge.Logic*.dll` 중 최신 로드

## 구현 중 변경

- `Guard`·`Career`는 로더(Api.cs)에 유지: KSP 기본 API만 쓰는 안정 코드라 이동 불필요(로직은 로더 타입을 참조)
- 이벤트 구독: AttitudeController·ThrottleLock·TriggerManager의 개별 Hook을 없애고 `BridgeLogic`이 onVesselChange·onGameSceneLoadRequested를 한 번 구독(델리게이트 보관) → Stop에서 Remove
- `/api/status`를 로더로 이동(version=로직 버전, loader_version, load_count, logic_error)
- 바이트 로드한 로직이 로더 어셈블리를 이름으로 찾도록 `AppDomain.AssemblyResolve` 처리 추가
- 빌드 시 로더는 `Plugins`, 로직은 `PluginData`로 자동 복사(각 csproj DeployToKsp)
- 같은 단순 이름 반복 로드 문제 확인(2026-11-08): 같은 이름이면 버전을 바꿔도(1.0.* → 1.0.9808.1927) Mono가 기존 어셈블리를 반환 → 로직 `AssemblyName`을 빌드마다 `KspBridge.Logic.yyyyMMddHHmmss`로, 배포 파일명은 `PluginData/KspBridge.Logic.dll` 고정(로더 변경 없음)

### 독립 리뷰 반영 (로직 0.4.4, reload_mod로 반영)
- 교체 직전 큐에 들어간 요청이 이전 로직에서 실행되어 해제 불가 상태를 다시 거는 경합 → 로직 경로를 감싸 `BridgeLogic.Stopped`이면 503 `logic_replaced`
- 트리거 루프: 앞선 동작이 트리거를 지웠거나 활성 기체가 바뀌면 건너뜀, 조건 평가 예외는 해당 트리거만 failed, 동작 실행 후 Prediction 캐시 무효화
- wait_until: 프로브 504(장면 전환으로 메인 스레드 정지)를 abort("game busy")로 변환
- 미반영(로더 변경 필요, 다음 로더 수정 때): reload 실패 응답에 이미 해제된 항목 목록 포함, `previous.Stop()` 예외 시 처리, Start 중간 실패 시 이벤트 구독 누수
