# KspBridge 커리어 1단계 — 개발 계획

선행: `0004-커리어1단계-방안.md`, `0005-커리어1단계-설계.md`

## 확인한 사실 (2026-11-07)
- `.craft` 형식(스톡 `Ships/VAB/Jumping Flea.craft`): `part = {name}_{id}`, `pos/rot`(기체 좌표), `attPos0/attRot0`(부모 기준), `istg/dstg/sidx/sqor/sepI`, `attm`(0 스택, 1 표면), `link = 자식`, `attN = {노드},{상대}_0|{y}|0`, `srfN = srfAttach,{부모}`, `sym = {대칭 짝}`, 이어서 `EVENTS/ACTIONS/PARTDATA/MODULE/RESOURCE`
- API 추가 확인: `KerbalRoster.DefaultCrewForVessel(ConfigNode, VesselCrewManifest, bool, bool)`, `GameEvents.OnVesselRollout`, `Contract.ContractID(long)`, `ModuleScienceExperiment.experimentActionName/resettable`, `PartCategories`, `Part.CrewCapacity`, `PartGeometryUtil.GetPartColliderBounds/MergeBounds`
- 결정: 계약 id는 `ContractID`(long). craft 생성은 **텍스트 생성 + 부품 `partConfig`의 MODULE·RESOURCE 복사**를 먼저 시험하고, VAB에서 안 열리면 메모리 `ShipConstruct`로 바꾼다

## 공통 규칙
- 각 단위 = Mod 핸들러 + 라우트 + App 도구 + App 테스트(도구→HTTP 매핑) + 게임 확인
- 게임 확인은 DLL 교체마다 KSP 재시작이 필요하므로, 단위별 코드 완료·빌드·App 테스트 통과 후 **게임 확인은 단위 순서대로 한 세션에서** 진행한다 (단위마다 별도 검증 기록)

```csharp
// 스택: 부모 노드 위치에 자식의 반대 노드를 맞춘다 (모든 스택 부품 회전 = identity)
AttachNode pn = parent.Prefab.attachNodes.First(n => n.id == spec.Node);
AttachNode cn = child.Prefab.attachNodes.First(n => n.id == Opposite(spec.Node)); // top↔bottom
child.Pos = parent.Pos + parent.Rot * pn.position - child.Rot * cn.position;

// 방사형: 부모 콜라이더 반지름 r, 높이 h에 symmetry개 원형 배치
Bounds b = PartGeometryUtil.MergeBounds(PartGeometryUtil.GetPartColliderBounds(parent.Prefab), parent.Prefab.transform);
float r = Mathf.Max(b.extents.x, b.extents.z);
for (int i = 0; i < sym; i++) {
    float ang = (spec.Angle + 360f * i / sym) * Mathf.Deg2Rad;
    Vector3 outward = new Vector3(Mathf.Sin(ang), 0, Mathf.Cos(ang));
    Quaternion rot = Quaternion.LookRotation(outward, Vector3.up);       // 자식 srf 노드가 부모를 향하게
    Vector3 srf = child.Prefab.srfAttachNode.position;
    child.Rot = parent.Rot * rot;
    child.Pos = parent.Pos + parent.Rot * (outward * r + Vector3.up * spec.Height) - child.Rot * srf;
}
```

```csharp
// own: OnFlyByWire 콜백
void Steer(FlightCtrlState st) {
    Quaternion target = SurfaceFrame.TargetRotation(_vessel, _pitch, _heading, _roll ?? CurrentRoll());
    Quaternion err = Quaternion.Inverse(_vessel.ReferenceTransform.rotation) * target;   // 기체 좌표계 오차
    Vector3 e = ToAxisAngle(err);                         // (x=pitch, y=roll, z=yaw) 라디안, KSP 기체축 매핑은 게임에서 확인
    Vector3 w = _vessel.angularVelocity;                  // 기체 좌표계 각속도
    st.pitch = Mathf.Clamp(_kp * e.x - _kd * w.x, -1, 1);
    st.yaw   = Mathf.Clamp(_kp * e.z - _kd * w.z, -1, 1);
    if (_roll.HasValue) st.roll = Mathf.Clamp(_kp * e.y - _kd * w.y, -1, 1);
}
// sas: 매 FixedUpdate
v.ActionGroups.SetGroup(KSPActionGroup.SAS, true);
if (v.Autopilot.Mode != VesselAutopilot.AutopilotMode.StabilityAssist) v.Autopilot.SetMode(VesselAutopilot.AutopilotMode.StabilityAssist);
v.Autopilot.SAS.LockRotation(SurfaceFrame.TargetRotation(v, pitch, heading, roll ?? CurrentRoll()) );

// 응답/상태: error_deg = Quaternion.Angle(현재, 목표)
```

### R1. own 조향 — 노즈 방향 제어

```csharp
Vector3 targetDir = SurfaceFrame.SurfaceRotation(v) * (Quaternion.Euler(-pitch, heading, 0) * Vector3.forward);
Vector3 nose = v.GetTransform().up;
Vector3 axisWorld = Vector3.Cross(nose, targetDir);                 // 노즈를 목표로 돌리는 축
float ang = Vector3.Angle(nose, targetDir) * Mathf.Deg2Rad;
Vector3 e = Quaternion.Inverse(v.GetTransform().rotation) * (axisWorld.normalized * ang);   // 기체 좌표: x=pitch, z=yaw
// roll 지정 시: 노즈 축 기준 현재 right와 목표 right 사이 부호 있는 각
```

- own 조향 부호 기본 -1(Settings.cs·settings.cfg), own 설정 시 SAS 끔
