# KspBridge 발사 중계 영상 — 방안

## 문제·목표
- KSP 비행을 누리호 중계처럼 영상으로 남기고 싶습니다. 녹화 구간은 발사 직전부터 목적지 도착까지입니다.
- 지금은 캡처, ffmpeg, 오디오, Azure 관련 코드가 없습니다. 모드가 App에 이벤트를 밀어 주는 경로도 없습니다. App은 `wait_until`, `get_flight_log`로 폴링만 합니다.
- 목표:
  1. 필요할 때만 켜는 인게임 화면 녹화
  2. 영상에 한국어 자막 입히기
  3. 카운트다운 소리와 "○○가 발사됩니다" 같은 안내 음성(Azure Foundry MAI-Voice)
  4. 카운트다운 T-0와 실제 점화 시점을 정확히 맞추기

## 검토한 대안
- **캡처 위치**:
  - App(.NET 10)에서 ffmpeg로 창 녹화 ← 채택
  - Logic(net472)에서 Unity ScreenCapture로 프레임 저장: 저장 I/O 때문에 프레임이 크게 떨어집니다. 채택하지 않습니다.
- **음성 모델**:
  - MAI-Voice-1은 현재 영어(en-US) 음성만 있습니다.
  - 한국어 음성(`ko-KR-Haena`, `ko-KR-Junho`)은 MAI-Voice-2-Flash에 있습니다. 두 모델은 같은 Azure Speech REST/SSML API로 호출합니다.
  - MAI-Voice-2-Flash 한국어를 기본으로 하고, 음성 이름은 설정으로 바꿀 수 있게 합니다 ← 채택
- **점화 연동**:
  - 카운트다운이 T-0에 점화까지 실행 ← 채택
  - 음성만 만들고 점화는 따로: 화면·음성·점화 시점이 어긋날 수 있습니다.
- **자막**: 입히기 + SRT, SRT만, 입히기만 중에서 입히기만 ← 채택
- **녹화 종료**: 목적지 조건으로 자동 종료, 수동 중지만 중에서 수동 중지만 ← 채택

## 채택 방안
1. **Logic: 중계 이벤트 버퍼**
   - 녹화 중에만 분리, 상황 변화, SOI 변경, 고도 돌파를 순번과 실시간 시각으로 쌓습니다.
   - App이 폴링해 가져갑니다. 이때 이벤트가 생긴 지 몇 ms 지났는지(`ageMs`)도 함께 받아 실제 시각을 복원합니다.
2. **App: 녹화**
   - ffmpeg `gdigrab`으로 KSP 창을 원본 파일로 녹화합니다.
   - 녹화 시작 기준 시각을 Stopwatch로 잽니다.
3. **App: 카운트다운**
   - 녹화를 시작한 뒤 카운트다운을 진행합니다.
     - T-20: "○○, 발사 20초 전입니다"
     - T-10…T-1: 숫자 읽기와 비프음
     - T-0: "발사!"와 함께 `/api/stage`로 점화합니다.
   - 카운트다운 음성은 녹화를 시작하기 전에 미리 합성해 둡니다.
4. **App: 안내 문구**
   - 이벤트를 한국어 문구로 바꿉니다.
     - 이륙: "○○가 발사되었습니다"
     - 분리: "1단이 분리되었습니다"
     - 고도: "고도 10킬로미터를 돌파했습니다", "대기권을 벗어났습니다"
     - 상황 변화: "궤도에 진입했습니다", "○○에 착륙했습니다", "착수했습니다"
     - SOI: "○○ 영향권에 진입했습니다"
   - 기체 이름 뒤의 조사(이/가)는 받침 유무로 고릅니다.
5. **App: TTS**
   - Azure Speech REST(`cognitiveservices/v1`)에 SSML을 보내고 WAV를 받습니다.
   - 같은 문구는 캐시해서 한 번만 합성합니다.
6. **App: 합성**
   - 녹화를 중지하면 두 번째 ffmpeg 패스를 백그라운드로 돌립니다.
     - 자막: ASS로 입힙니다.
     - 음성: `adelay`로 제 시각에 놓고, 비프는 `sine`으로 만들어 `amix`로 섞습니다.
   - 결과는 MP4 하나입니다.
7. **MCP 도구**: `start_broadcast`, `stop_broadcast`, `get_broadcast_status`
8. **설정**
   - YAML에 ffmpeg 경로, 출력 폴더, 창 제목, 프레임레이트, 글꼴, Speech 리전·키·음성을 둡니다.
   - API 키는 OsKms로 암호화합니다(rule `dotnet/kms-config-secrets`).

## 결정 (2026-11-08 사용자)

- 음성: MAI-Voice-2-Flash 한국어 기본, 설정으로 변경 가능

## 비범위
- 목적지 자동 도착 판정과 자동 중지
- SRT 별도 파일
- 생방송 송출, 실시간 음성 재생(음성은 영상에만 들어갑니다)
- 시간 가속 구간 편집(가속 중에도 그대로 녹화됩니다)
- 사용자 지정 문구 도구(announce)
- 점화 전 Δv 점검 자동화. 기존 rule `ksp/launch-preflight`대로 Claude가 도구를 호출하기 전에 합니다.
